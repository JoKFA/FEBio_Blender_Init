# Spec v0.1：用 FEBio 替换实验室控制器下的 Ziva

日期：2026-10-27。依据：实验室论文 *Beneath the Skin*（投稿中，不入库）与演示视频（9-24 版）。

## 背景

实验室的研究贡献是**控制器层**：每块组织采样约 300 个 landmark，每个绑定约 20 个顶点；用梯度下降优化 landmark 的平移/旋转（距离 + 应变能 + Hill 肌肉功，限速），再用 co-expression 重叠和预计算转换矩阵做成钢琴式交互。**物理计算交给 Ziva**（Maya 2023 + mayapy，Python 3.9）。Ziva 已停售，许可到期后这套研究流程没有物理后端。

## 目标

在 Blender 里加载实验室的下颌资产（颅骨固定、下颌刚体、牙齿、嘴唇组织、attachments），用实验室**已算好的一条 landmark 轨迹**驱动，FEBio 做正向动力学仿真，结果回放到 Blender，并与同一轨迹的 Ziva 结果逐顶点对比。

## 非目标（v0.1）

- 移植控制器的优化部分（梯度下降、co-expression、转换矩阵）
- 主动肌肉本构：实验室的“收缩”是 landmark 运动学驱动，Hill 模型只在优化目标里
- 接触与滑动：实验室在 Ziva 里关掉了（论文 3.7、4.1.3）
- 皮肤层（注册、wire deformer）：本资产的嘴唇本身就是肌肉
- 与 Ziva 逐点数值等价：本构和积分器不同，只在约定指标和容差内比较

## 架构

```
实验室控制器（Python）
      │ landmark 轨迹（每帧变换）
      ▼
SimBackend 接口（我们定义）
  ├─ Ziva（现有，在 Maya 里出参考结果）
  └─ FEBio（我们做）：场景 IR → .feb → 动力学求解 → 逐帧顶点
      │
      ▼
Blender add-on：加载资产、看 landmark、选轨迹、Run、回放
```

- `asrp_core` 在独立进程和独立 venv 里运行，不依赖 `bpy`；Blender 只通过子进程调用它（已验证，见 A2）。
- 单位统一为 mm–N–MPa–s，换算写进每个文件。
- 每次运行记录输入哈希、软件版本、参数。

## Spike 顺序

1. ✅ **S1 FEBio 本机可用**（2026-10-27）：生成最小 `.feb`（四面体组织柱 + 刚体下颌，`center_of_mass` 设在铰链上实现绕关节转动 + 重力，动力学 30 fps），命令行求解，解析逐帧位置。验证 A3，发现 A14、A15。
2. **S2 资产四面体化**：对实验室嘴唇网格做四面体化，记录失败点。验证 A10。
3. **S3 landmark 驱动**：按 Q1 的答案实现驱动方式，用参考轨迹跑一段，和 Ziva 对比。验证 A5、A11。

## 端到端验收

在 Blender 里打开实验室资产，选参考轨迹，Run → FEBio → 回放；脚本计算嘴唇顶点与 Ziva 结果的逐帧误差，低于实验室给的容差；同一输入重复运行结果一致（哈希相同）；输出全部可追溯到输入。
