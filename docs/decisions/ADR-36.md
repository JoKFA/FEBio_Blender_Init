## 当前生效结论

1. **物理尺度 `k` 按真实坐标进出 FEBio（持续生效，补充 [ADR-22](ADR-22.md)、[ADR-31](ADR-31.md)）**：
   - FEBio 模型按真实大小写：每个节点坐标（四面体节点、刚体枢轴、嘴角的锚、弹簧端点）= 几何毫米 × k。
   - 所有物理参数（杨氏模量、泊松比、密度、重力 9810 mm/s²、弹簧刚度 N/mm）都是真实物理值，不缩放。
   - 读回结果除以 k 换回几何毫米；FEBio 读到的应变能就是物理能量，不用换算；k = 1 与不缩放模型逐位相同（做法见 [05](../05-ziva-to-febio.md) 第 2 节）。
2. **粘连的对应与新旧分流（2026-11-24，[ADR-48](ADR-48.md)、[ADR-51](ADR-51.md) 补充）**：
   - **旧嘴唇（`legacy-v1`）保留本条做法**（取代原 [05](../05-ziva-to-febio.md) 第 3 节“最近边界计算点”规则）：
     - 每个被粘显示顶点使用显示嵌入时的同一个四面体（包含它的，在外面取最近边界四面体）的 4 个计算点和重心坐标 λ。
     - `hard`：节点取并集并入刚体；因重心插值是仿射的，显示顶点精确跟随骨头。
     - `spring`：节点集与 `hard` 相同；节点 j 写三根弹簧（沿目标刚体 x、y、z 轴，另一端为并入刚体的锚点，偏出 δ ≥ 10 × 最大滑移；实现取 5 倍四面体边长中位数 × k）。
       - 每根刚度 = 基础刚度 × Σ w·λ̂，λ̂ = (λ̃ + 1/4)/2（λ̃ 为负值截 0 再归一的 λ，加平均分配一半保证四角有刚度、加硬时收敛到 `hard`）；刚度分档到每节点相差不超过 2%。
     - 冲突处理、按组报告和 2 倍边长中位数保护见 [05](../05-ziva-to-febio.md) 第 3 节。
   - **新场景可变形目标粘连（地基目标，待实现）**：改按 [ADR-51](ADR-51.md)（逐点面积加权、目标四面体外推参考点纯罚线性约束与后端按单元对等价合并）。

## 依据与边界

- **来源**：本条来自 2026-11-11 的一次独立审查（独立第三方），对照实验室源码、论文和演示视频，指出 [ADR-22](ADR-22.md) 的等价做法和 [05](../05-ziva-to-febio.md) 第 3 节的最近点规则各有一处会做错（梳理见 [E-07](../archive/explanations/E-07.md)）。
- **原因**：
  - 第 1 条：另一种等价做法“密度乘 k²、重力除以 k”需给弹簧刚度另给 K/k、能量乘 k³，每个量一条规则、容易写错；用真实坐标，换算只在进出各一处。
  - 第 2 条：最近点规则下，四面体的另外 3 个角是自由的，`hard` 显示顶点变形时会离开骨头，过不了 [07](../07-validation.md) 第 3 节 0.001 mm 检查；`spring` 和 `hard` 节点集不同，刚度趋于无穷也收敛不到 `hard`。
- **实测验证（2026-11-11 [T-07](../archive/tasks/T-07.md) 第 1、2 步）**：
  - `uv run python tests/s3_attachment.py`（FEBio 4.13）：节点坐标 × k、物理参数不缩放的做法在带弹簧时成立（悬挂方块 k = 2 误差 0.0165%）；`spring` 节点集与 `hard` 相同，刚度加硬时单调趋近 `hard`。
  - 实测发现零长度单根弹簧（锚点与节点重合）FEBio 算不出刚度，故修正为每节点三根沿 x、y、z、带偏移 δ（≥ 10 × 最大滑移）的弹簧（不改本 ADR 决定）；全部数字和取法只写在 [05 归档](../archive/prototype/05-v1-attachment-trials.md)“T-07 第 1、2 步的结果”。
  - [T-07](../archive/tasks/T-07.md) 第 3 步（权重小于 1，`A-23`）推后到第二阶段。
- **影响**：[05](../05-ziva-to-febio.md) 第 2、3 节、[04](../archive/prototype/04-v1-architecture.md) 第 5.1 节、[07](../07-validation.md) 第 3 节、[术语表](../glossary.md)。
  - 关联任务：[09](../09-roadmap-and-tasks.md) 的 [T-06a](../archive/tasks/T-06a.md) 与 [T-07](../archive/tasks/T-07.md)。
