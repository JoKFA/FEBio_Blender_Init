## 当前生效结论

- **判定对象**：判断两次运行是否相同，比较解析出的每帧坐标和回放文件，不比较 FEBio 的原始日志。
- **同环境复现（(a)，[ADR-38](ADR-38.md) 修订后现行标准）**：
  - 默认（4 线程）：同一台机器、同一份输入重跑（含把运行文件夹拷到另一个目录、只用它自己的文件重跑），每帧每个点的坐标差不超过 1×10⁻⁹ mm（实测最多差 1×10⁻¹⁰ mm）；
  - 回放文件逐位相同只在 `--threads 1` 时保证。
- **跨环境复现（(b)，R-06）**：
  - 另一台 Windows 电脑、另一个文件夹，只用运行文件夹自己的文件重跑；容差先量再定，M5 验证。
- **2026-11-24 扩展口径（[ADR-48](ADR-48.md)、[ADR-49](ADR-49.md)、[ADR-51](ADR-51.md) 补充）**：
  - 旧场景迁移回归：沿用同环境全帧全原序点 `1e-9 mm`（1 线程与默认线程分别记录，PC2 按 float32 验）；
  - 会话重放口径：字节摘要抓损坏、数值参照按容差抓漂移，换 FEBio 构建或环境标明来源，续算容差单列不替代迁移门限；
  - 后端按单元对等价合并：采用数值容差口径（不要求不同装配次序下浮点逐位相同）。

## 依据与边界

- **日志与坐标实测**：实测同一模型跑两次，日志不同（里面有时间戳），坐标最大差 1×10⁻¹³ mm，回放文件逐位相同（[11](../11-risks-and-questions.md) 的 A-24）。由 `tests/test_febio.py` 的 `test_s1_repeats_within_tolerance` 每次检查（默认线程两次坐标差 ≤ 1×10⁻⁹ mm，单线程回放文件逐字节相同）。
- **跨环境约束**：CPU 指令集和求解器的多线程使跨机器逐位相同不现实；实验室的机器和文件夹是几个人共用的（[14](../14-ziva-demo-walkthrough.md) 第 1 节），跨人复现是真实用法。

## 历史与修订

- **2026-10-29 初版**：判断两次运行是否相同，比较解析出的每帧坐标（差别 ≤ 1×10⁻⁹ mm）和回放文件，未区分线程数。
- **2026-11-11 补充**：将复现分为 R-06 两层——(a) 同环境要求每帧坐标 ≤ 1×10⁻⁹ mm 且回放文件逐位相同；(b) 跨环境容差先量再定，M5 验证。
- **2026-11-11 修订（[ADR-38](ADR-38.md)）**：将 (a) 的标准改为默认（4 线程）坐标差 ≤ 1×10⁻⁹ mm（实测最多差 1×10⁻¹⁰ mm），回放文件逐位相同仅在 `--threads 1` 时保证；原文保留不动。
- **2026-11-24 状态**：由 [ADR-48](ADR-48.md)、[ADR-49](ADR-49.md)、[ADR-51](ADR-51.md) 补充旧场景迁移回归、会话重放与后端按单元对等价合并三类口径。
