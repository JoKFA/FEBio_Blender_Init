## 当前生效结论

1. **独立打包 `asrp_query` 与进程内复用**：
   - 训练查询独立打包为可单独安装、由 **Python 3.9 进程内调用**的 `asrp_query` 包，一次载入静态数据后在内存反复按姿态返回数组，不推进物理时间。
   - 核心（Python 3.13）负责从场景版本生成查询静态数据；3.13 的 `results` 复用同一份几何运算。
   - 新入口 `asrp_query.open_query(static_path)`（待实现）返回一次载入、可反复按姿态查询的模型，静态数据格式 `asrp-query-data/1`（待实现）。
   - 保留现有 `rest_model`、`final_shape` 的调用路径和嘴唇返回形状作为兼容适配，五张表面的新查询用独立方法，不把旧函数的单个数组改成五项。
2. **Python 3.9 兼容边界**：
   - `asrp_query/__init__.py`、静态数据读取与身份校验、坐标转换、蒙皮、刚体枢轴变换及其全部传递依赖和包安装元数据必须守 Python 3.9（首版限制，是我们选的、不是实验室的要求：只依赖标准库及实测兼容的 NumPy），**禁止导入 `asrp_core`**。
   - 场景迁移、会话、FEBio、Blender、Ziva 比较和沉降读取器留在核心。
   - 开发机须在干净的 Python 3.9 解释器中于仓库外做独立安装与查询验证，故意让入口导入 `asrp_core` 必须失败。
3. **默认基底与输出范围**：
   - 默认正式基底是未沉降的静止形状，对外保留实验室的绝对世界位置、场景单位、Y 向上约定。
   - 输出从嘴唇一组扩展到四组 landmark 所在网格（嘴唇、左眼、右眼、额肌）加下颌网格；现有 145 份结果只给嘴唇静止查询作证，其余输出各设独立裁判（下颌用已知偏心枢轴转动、眼额用单侧扰动抓左右对调）并等本家族原序参考。
4. **现在不定**：
   - 实验室训练最终使用的 Python 解释器、NumPy 构建/ABI、非中性初始化的真实操作基准，以及研究员对载入和热查询耗时的可接受上限，等上机在实验室实际训练进程中实测并由研究员确认；在此之前按 Python 3.9 独立包与静止基底推进。

## 依据与边界

- **原因**：
  - 训练循环不推进时间但查询频次高；本机计时表明每次起 CLI 子进程的纯启动开销就比内存热查询慢近两个数量级，必须进程内复用。
  - 已知实验室 Maya 自带 Python 3.9（实际训练调用进程及 NumPy 构建待上机确认，[11](../11-risks-and-questions.md) 的 `D22`），而核心使用 Python 3.13；开发机先证明干净 3.9 能独立安装。
  - 训练走静态模型，不需要状态、帧或结果清单；现行 `final_shape.py` 顶层直接导入整个 `scene` 模块，不单独拆包无法在 3.9 下独立安装。
  - 实验室源码显示训练每步同时读取四组 landmark 网格与下颌，现有原型只覆盖了嘴唇。
- **证据（[E-23](../archive/explanations/E-23.md)）**：
  - 本机计时（2026-11-24，Python 3.13，真实嘴唇 10,240 个顶点）：载入模型 `219–272 ms`，内存内热查询（50 次中位数）`3.1–3.6 ms`，起一个 CLI 子进程（不载入模型）约 `275 ms`；**实验室 Python 3.9 环境耗时未量过**。
  - 源码核查：现行 `final_shape.py` 第 41 行顶层导入 `scene`；实验室源码（提交 `506cd69`）训练环境读取嘴唇、左右眼、额肌和下颌五张网格且不推进物理时间。
  - 既有边界（[ADR-30](ADR-30.md)、[ADR-42](../archive/decisions/ADR-42.md)）：145 份实验室训练存档落在未沉降静止形状上（嘴唇最坏差 `0.000007 mm`，但缺逐份场景身份且未覆盖其余四张网格）。
- **重开条件**：实验室实际运行环境给出相反证据——包括实际训练解释器不是 Python 3.9、NumPy ABI 不兼容、真实非中性原操作需要物理沉降基底、或热查询耗时不能满足研究员要求时，重开本条。

---

## 历史与修订

- **放弃的方案**：
  - 每次查询起一个 CLI 子进程：启动耗时约 275 ms，远高于 3.1–3.6 ms 的内存查询；
  - 要求训练端安装并导入完整的 Python 3.13 `asrp_core`：与实验室 Python 3.9 环境冲突；
  - 用重力沉降后的形状冒充既有静止训练基底：与实验室 145 份历史训练结果不符。
