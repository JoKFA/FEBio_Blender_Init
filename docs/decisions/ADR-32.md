## 当前生效结论

- **粘连权重表读法更正（已证实，范围限定当前演示场景家族）**：
  - 粘连权重表里文件没存的元素取默认值 **1.0**（已由 `A-33`、[E-11](../explanations/E-11.md) 证实），根本没存权重表的粘连等于整块出发方都粘着。
  - 原读法把没存的当 0，因此“嘴唇 → 颅骨 0 个顶点”是错的：实际是 **74 个上唇顶点**（数字和链条见 [03](../03-asset.md) 第 2 节）。
  - 2026-11-24 限定范围（[ADR-51](ADR-51.md)）：“未存权重默认 1.0”仅适用于当前演示场景家族，不推广到第二族场景，待取数核实。
- **旧嘴唇（`legacy-v1`）现行物理范围与配置**：
  - 两种旧嘴唇（`ours` 与 `ziva-soft`）共用 `legacy-v1` 建造配置，保留已落盘的 N/mm 刚度与分档，改材料不重算旧弹簧（[ADR-48](ADR-48.md)）。
  - 细网格默认粘连未变：上唇 `hard`（`asrp import-asset --attachments` 默认 `ours`，`src/asrp_core/cli.py:351`）。全改软约束已在 [T-37](../archive/tasks/T-37.md) 第 2 项量过、未采用。
  - `ziva-soft` 是现成选项，Blender 面板配粗格子时使用（`blender_addon/asrp_blender/asset.py:92`，[ADR-44](ADR-44.md)）。
  - 第一阶段嘴唇的四项原型范围约定（保留于旧嘴唇）：
    1. **两组直接粘连**：上唇 74 个顶点连颅骨（`zAttachment1`）默认用 `hard`（颅骨固定，没有“算两遍”的问题）；下唇 76 个顶点连下颌（`zAttachment2`）用 `spring`，基础刚度为参数，硬绑是刚度趋于无穷的极限。
       - 注：上唇 `hard` 属近似，Ziva 140 个粘连全是软约束，刚度 1×10⁸ N/m³（[03](../03-asset.md) 第 5 节，需乘面积才是弹簧刚度，[E-14](../archive/explanations/E-14.md) 第 3 条）。
    2. **两侧嘴角近似**：连到口角 node 的两组顶点（`zAttachment9`/`zAttachment10`，348 / 309 个）不建整条链“口角 node → zTissue2/3 → 颅骨和下颌”。
       - 用 `spring` 连到介于颅骨和下颌之间的嘴角锚上；混合比例和基础刚度为参数，默认值标“我们定的”（对应与锚做法见 [05](../05-ziva-to-febio.md) 第 3 节）。
    3. **以嘴唇为目标的粘连不建**：周围 6 块肌肉、9 组皮肤粘在嘴唇上，第一阶段不建；属简化，在 [T-06a](../archive/tasks/T-06a.md) 运行报告写明。
    4. **[ADR-27](../archive/decisions/ADR-27.md) 保留**：下唇 76 个顶点基础刚度为参数，等 Ziva “只有物理”结果量出下唇跟随比例后定。
- **新场景通用粘连（地基目标，待实现）**：改走三层表达、逐点面积加权与可变形目标仿射外推纯罚候选（[ADR-51](ADR-51.md)）。

## 依据与边界

- **原因**：
  - 实验室会议指出嘴唇不只连在别的肌肉上，嘴角也连着骨头；读法更正后上下唇各有直接连骨顶点，嘴角经口角组织间接连颅骨和下颌（[03](../03-asset.md) 第 2 节），四组顶点互不重叠。
  - 整条嘴角链需补回口角 node 和 zTissue2/3 网格，它们只在 Ziva 存的副本里（[12](../12-lab-export-checklist.md) 第 7 项），第一阶段先用近似。
  - [T-04](../archive/tasks/T-04.md) 下颌张开试验说明固定区和随下颌区之间需留过渡带，一刀切会不收敛（[E-03](../archive/explanations/E-03.md)）；按真实粘连区域挂、嘴角用软弹簧正符合此点。
- **影响**：[03](../03-asset.md) 第 2 节、[05](../05-ziva-to-febio.md) 第 3 节、[11](../11-risks-and-questions.md) 的 `P-01`、`A-21`、`A-33`、`A-35`。
  - 关联任务：[T-03](../archive/tasks/T-03.md)、[T-06a](../archive/tasks/T-06a.md)。

## 历史与修订

- **2026-11-10 初定与放弃项**：
  - 当时默认值 1.0 为强推断，待 Ziva 机器导出的 `ziva_maps.json` 的 `default` 字段确认（`A-33`）。
  - 放弃了：[ADR-13](../archive/decisions/ADR-13.md) / `P-01` 方案 A“按区域重新挂到骨头上”（现已有真实骨头粘连）；方案 B（加口角、zTissue2/3、周围肌肉和皮肤）推到第二阶段等 Ziva 网格；方案 C、D 仍不用。
- **2026-11-12 补充（[ADR-40](../archive/decisions/ADR-40.md)，后随 ADR-40 退役）**：
  - 实测嘴角锚混合比例 α = 0.5 与弹簧刚度敏感度：α 差 0.2 时形状差 4.8 mm，弹簧刚度除以 10 差 0.95 mm（[E-09](../archive/explanations/E-09.md)）。
  - 当时称 AA 目标里嘴角完全不动，数据不利于 0.5，但目标不含物理（推断），所以默认值不改、[T-27](../archive/tasks/T-27.md) 在 0 到 1 之间扫 5 个值报告（`A-35`）。
- **2026-11-13 状态更新**：
  - 默认值 1.0 已证实（`A-33`、[E-11](../explanations/E-11.md)）；注明第 1 条上唇 `hard` 是近似（Ziva 为软约束 1×10⁸ N/m³），改软约束归 [09](../09-roadmap-and-tasks.md) 的 [T-37](../archive/tasks/T-37.md)。
  - 2026-11-12 补充里“AA 目标里嘴角完全不动”是在美术目标文件上量的，不代表实验室运动结果（[ADR-25](ADR-25.md) 状态行），不再作为证据。
- **2026-11-24 状态更新**：
  - 细网格默认保持 `ours`（上唇 `hard`），`ziva-soft` 供选项及粗格子面板使用；2026-11-12 补充里“扫 5 个嘴角锚比例”随 [ADR-40](../archive/decisions/ADR-40.md) 退役。
  - [ADR-48](ADR-48.md) 与 [ADR-51](ADR-51.md) 确立 `legacy-v1` 旧嘴唇与新场景通用粘连分流，并限定默认值 1.0 的家族边界。
