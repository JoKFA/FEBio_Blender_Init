## 当前生效结论

1. **新会话段默认分段线性插值**：在相邻关键点之间匀速改变控制量；首版段格式不要求研究员输入接头处的控制速度。
2. **旧整段平滑显式保留**：原有整段运动的单调三次 Hermite 平滑曲线及实际采样作为显式选项保留；明确要求平滑的新段只用该段已知关键帧及父末值生成，端点用单侧规则，一次生成即封存，不承诺接头速度连续。
3. **实际样本提交后封存**：
   - 每段保存实际交给 FEBio 的驱动曲线取样值，求解器重放只读已保存样本。
   - 第一版承诺两件事：① 追加绝不改写已提交旧段的样本；② 同一串关键点按相同分段线性规则取样时，切段本身不制造差别——同一起点、同一组实际样本、相同求解设置和步序下，整算与分算须在已登记容差内一致。
   - 把同一批关键点换切点或拼回整段重新平滑属于另一条输入，结果可能不同。
4. **给研究员的使用说明须写清上述差别**（说明原文见 [会话、检查与结果规范](../architecture/sessions-and-results.md)，原 [04](../architecture/README.md) 第 13.12 节末尾）：
   - 每按一次键从上次结束的姿态和运动状态继续，新段默认匀速改变控制量、接头处控制速度可能改变；
   - 重做整段平滑接头附近驱动和软组织运动可能不同；
   - 复现须使用保存的各段和实际驱动样本。
5. **现在不定**：接头处控制速度突变是否会对实验室研究任务造成可重复、显著的影响，等取得实验室真实连续两次按键边界两侧的驱动记录后再评估，首版不加可选端点速度字段。

## 依据与边界

- **原因**：
  - 交互按段推进时下一次按键尚未发生，不能事后用未来关键帧改写已提交的历史段；同时既有 [T-33](../tasks/T-33.md) 连平滑方案在既定甩头门限下也未收敛，没有依据把平滑定成物理默认。
  - 封存实际样本把“切段会不会改历史”和“换切点重拟合会不会改驱动”明确拆开，既保住旧整段回归，又让已提交实验可按已存样本重放：样本逐字节核验，同环境重算按登记数值容差比较，换求解环境另立记录。
- **证据（[E-23](../archive/explanations/E-23.md)）**：
  - 插值复算（`generate.py` 第 221 行）：同一旧平滑函数对 `[0, 1]` 和 `[0, 1, 0]` 在首个区间中点分别算出 `0.5` 和 `0.625`，证明追加未来关键帧会改写过去。
  - 本机 FEBio 会话实测（2026-11-24）：帧间线性插值（实测与线性差 `4.9×10⁻¹¹ mm`）下，三种第一段写法（写到第 22 帧、写完整、第 22 帧后换另一运动）在第 0–22 帧差 `0 / 0 / 0`，整算与分段续算最大差 `1×10⁻¹⁰ mm`。
  - 历史证据（[T-33](../tasks/T-33.md)）：平滑方案在既定甩头门限下未收敛。
- **重开条件**：真实连续按键记录显示接头处控制速度突变会显著、可重复地影响研究任务，且实验室调用侧能取得对应的端点速度及单位时，重开本条以增加可选端点速度的段格式。

---

## 历史与修订

- **放弃的方案**：
  - 追加新段后重新拟合整段历史平滑曲线：破坏“过去不被追加改写”的会话承诺；
  - 直接删除旧整段平滑：破坏既有整段运行的复现与回归对照；
  - 首版强制要求提供接头端点速度：缺乏真实按键敏感性证据，平添输入负担。
