# ADR-07：产品用的数据一律来自实验室导出的开放格式；.mb 只用来核对

| 项目 | 内容 |
|---|---|
| **状态** | ✅ 已定（2026-10-29；"谁来导出"已被 [ADR-18](ADR-18.md) 取代） |
| **关联决策** | [ADR-18](ADR-18.md) |

## 当前生效结论

- **开放格式为产品唯一数据来源**：网格导出成 OBJ（或 FBX、Alembic），Ziva 设置导出成属性清单，蒙皮权重导出成权重文件。
- **`.mb` 仅用于核对**：从 `.mb` 里读出的东西（结构、顶点坐标、权重）**只用来核对**这些导出，不作为产品的数据来源。
- **导出分工修订**：原决定写由实验室导出，"谁来导出"已被 [ADR-18](ADR-18.md) 取代。

## 依据与边界

- **原因**：`.mb` 的格式没有公开文档。顶点坐标和大部分属性我们读出来了，但网格的"面"读不出来，还有 41 个数据块的格式没认出来。产品不能建立在猜出来的格式上，Maya 版本一换就可能失效。
- **放弃了**：继续破解 `.mb` 的网格编码。

## 历史与修订

- **2026-10-29**：定案，规定网格由实验室导出成开放格式，`.mb` 只用来核对。
- **更正**：本条的早期版本说"下颌有 3 个坏点、颅骨有 14,204 个坏点"，那是读错了顶点数（把坐标数值的个数当成了顶点数）造成的，按正确的读法没有坏点。
- **部分取代**："谁来导出"已由 [ADR-18](ADR-18.md) 取代。
