## 当前生效结论

1. **双网格并存与默认选择**：
   - 产品多一个可选四面体网格 `data/tetmesh/lips_lattice.json`，与细网格 `lips.json`（[ADR-20](ADR-20.md)，一字节未动）并存。
   - **导入命令默认仍是细网格**，通过 `--tetmesh` 选用；**Blender 面板默认是粗格子**（2026-11-15 定，[E-20](../explanations/E-20.md)），因实验室的参照是 Ziva，粗格子在实验室运动上离它更近且约一秒算完，细网格在面板上可选。
   - 粗格子不能用硬粘连（会连带固定上下唇共用节点），须配软约束（`asrp import-asset --attachments ziva-soft`，[05](../05-ziva-to-febio.md) 第 3 节）。
2. **生成方法（轴对齐立方格子 + 6 Kuhn 四面体）**：每格沿 (0,0,0)–(1,1,1) 对角线切 6 个四面体（邻格面自动对上），节点焊接，全正体积。留格规则：表面采样点（每顶点 + 每三角形上间距 ≤ 格边 1/4 的重心网格点）落在格里，或从该格走不到外面（6 邻接空格，填充封闭壳内部）；规则写入 `params.cube_rule`。
3. **格边来自 Ziva 换算**：格边 = Ziva `tetSz` 26.37 场景单位 × 0.962 = 25.368 mm（[03](../03-asset.md) 第 5 节），非调参得出，来历写入 `params.cell_mm_source`。
4. **原点事先规则化**：原点 = 嘴唇表面包围盒最小角，不按离 Ziva 距离挑选；位置敏感性只报告（见平移半格实测）。
5. **上下唇不分开**：同格含上下唇时不沿嘴缝切开，复现 Ziva 整体运动行为；文件显式记录 `upper_and_lower_lip_separated: false` 与 `warning`。
6. **格式区分与独立检查**：用 `kind` 字段区分（缺省为细网格，不改旧 `lips.json`；`"lattice"` 为格子），由 `tetmesh.mesh_kind(meta)` 读取，`load` 遇未知 `kind` 报错；格子走 `tetmesh.check_lattice`，细网格 `tetmesh.check`（分开宽度、边界流形、亏格）不放松（焊接的格子本来就没有这些性质，对它们问这些没有意义）。
7. **格子检查项（记入 `checks`）**：全正体积、最小体积与最小二面角不低于细网格下限（`MIN_TET_VOLUME_MM3`、`MIN_DIHEDRAL_DEG`）；单连通；无被三个以上四面体共用的面；每显示顶点落在四面体内（容差 10⁻⁶ mm）；嵌入静止显示网格等于嘴唇表面（容差 10⁻⁶ mm）；同输入重建内容哈希相同。
8. **确定性生成**：无随机数、无第三方网格包；`uv run python tools/build_tetmesh.py --method lattice` 先建两遍比对哈希再写（`--cell-mm` 可改格边，默认即第 3 条换算；默认 `--method fine` 及输出不变）。
- **2026-11-24 地基补充（[ADR-47](ADR-47.md)、[ADR-48](ADR-48.md)）**：规则格子允许在建造时确定性生成，并将其节点、单元、顺序、参数（含原点规则）和生成器版本一并封存进建造记录，由建造配置选用；旧嘴唇的 `ziva-soft`（含粗格子搭配）与 `ours` 共用 `legacy-v1` 建造配置并保留存量刚度。

## 依据、实测与代价

- **原因**：2026-11-15 在中性到 AA 上，细网格（26,721 四面体，上下唇沿嘴缝分开）几乎不带动上唇中部（0.15–0.22 mm），Ziva 为 4.80 mm；细网格里上唇只靠自己的几十个弹簧挂着，Ziva 网格粗到嘴缝无逢、上唇被下颌带着走。规则格子复现此行为且更快、确定、不怕自相交、无第三方依赖（对应 [T-20](../tasks/T-20.md)）。
- **实测对比**（2026-11-15；AA 运动 `data/lab_export/trajectories/neutral_to_AA.json`；全软弹簧刚度 = Ziva 0.1 N/mm³ × 平均顶点面积 × k²）：
  - 场景为 `import-asset` 副本，当时改软脚本在仓库外（因为 `--attachments ziva-soft` 选项另有人在做）；对 Ziva 全脸第 36 帧全部顶点（mm）。
  - **FEBio 时间为其自身计时行，机器当时有别任务，只作量级参考**：

| 网格 | 四面体 | 平均 / p95 / 最大 | 上唇中部走的距离 mm | FEBio 秒/帧 |
|---|---:|---|---:|---:|
| 细网格（`lips.json`） | 26,721 | 2.278 / 4.825 / 7.647 | 0.22 | 0.828 |
| 格子，原点 = 包围盒最小角（产品） | 126 | 1.883 / 3.597 / 5.116 | 5.51 | 0.012 |
| 同上，平移半格（z） | 168 | 2.191 / 4.145 / 5.806 | 5.55 | 0.049 |
| 同上，平移半格（x） | 132 | 1.887 / 3.638 / 5.314 | 4.78 | 0.020 |
| 同上，平移半格（y，顺带） | 162 | 2.111 / 3.882 / 5.247 | 4.93 | 0.020 |

- **更多实测指标**：
  - Ziva 上唇中部走 4.80 mm；格子位置影响范围最大 5.1–5.8 mm、平均 1.88–2.19 mm，但各位置上唇均被带动（4.8–5.6 mm）。
  - 产品格子文件：56 节点、126 四面体、21 格；最小四面体体积 2,720.8 mm³、最小二面角 45.00°；0 个显示顶点在四面体外，嵌入静止最大差 2.95×10⁻¹⁴ mm；两次生成内容哈希均为 `a8dc3c51e57a…`。
  - 三种运动均 0 次重试，五项合理性检查通过（(b) 无硬附着为“未运行”）：四面体体积比 AA 为 0.953–1.298，甩头 0.993–1.008，张嘴 12° 为 0.880–1.717（细网格 0.736–5.005）。
  - 显示表面（只报告）：AA 物理层格子 0 翻转面、0 条过短/过长边（细网格 0 翻转、6 条边长过 2 倍）；张嘴 12° 格子 0 翻转（细网格最多 3 翻转、273 条边长过 2 倍）。
  - 张嘴 12° 第 32 帧对第 14 帧（无 Ziva 可比）：格子上唇中部走 12.1 mm、下唇中部 22.4 mm、嘴张开量（上下唇中部高度差变化）9.3 mm；细网格 0.4 mm、28.3 mm、27.0 mm。
  - 格子里上唇跟着下颌走，这和 AA 里贴近 Ziva 是同一件事，但 12° 张嘴没有 Ziva 的结果可比。
  - 甩头：格子嘴唇相对头最大晃动 0.087 mm（细网格同设置 0.146 mm）。
- **代价**：嘴缝窄的运动（嘴唇闭合、上下唇各自动）在格子上做不到，需上下唇分开动的研究仍用细网格；位置规则固定后仍有 ±半格量级敏感性。
- **影响**：[09](../09-roadmap-and-tasks.md) [T-20](../tasks/T-20.md)、`src/asrp_core/tetmesh.py`、`tools/build_tetmesh.py`、`tests/test_tetmesh_lattice.py`、[ADR-20](ADR-20.md) 状态行。

## 历史与修订

- **放弃的方案**：
  - (a) 去掉细网格、只留格子：上下唇分开动的研究仍需细网格；
  - (b) 把格子对齐到嘴缝格平面：试过格边 25 mm、嘴缝在格平面上，得 180 四面体、上唇走 6.06 mm（离 Ziva 的 4.80 更远，且属按结果挑位置）；
  - (c) 把嘴缝切开：格边 12.5 mm 沿嘴缝分开试验得 684 四面体，上唇只走 0.82 mm，与细网格一样不带动上唇。
