## 当前生效结论

1. **切开静态计算模型与单段运动**（即整次实验固定的计算模型与本次提交才知道的运动）：
   - 第一刀切在 `generate.build()`：`build` 模块根据**场景版本**和**建造配置**生成一次会话锁定的不可变**建造记录**。
   - 只实现 FEBio 一个后端（`backends/febio`），首次输入与重启输入共享同一份编号表（模块布局和何时再抽象通用后端见 [建造与粘连规范](../architecture/build-and-attachments.md)，原 [04](../architecture/README.md) 第 13 节）。
2. **独立建造配置与可重放建造记录**：
   - **建造配置**是独立、可校验、带版本的 JSON：随代码发布具名配置（两种旧嘴唇共用 `legacy-v1`，新演示场景用另行命名的 `demo-v1`，未验证近似由研究员显式选择），由 CLI 或插件传入。
   - **建造记录**封存完全展开的有效配置、来源和摘要、静态模型、实际计算网格与内容摘要、每张显示面绑定、每条粘连边对应与后端实现记录、有效材料/刚度/物理尺度、驱动通道、编号表、翻译记录及足以重放的数组。
   - 建造清单放会话 `build/`，数组和网格可按摘要放同一项目库 `blobs/` 共享；清单必须能找到并验证全部真实字节，清会话缓存不删它们；搬走或导出会话须连同内容打包或明确校验定位同库。
   - 各段封存本段实际送进 FEBio 的输入、样本和设置，尝试目录存执行副本与日志；根起步写首份 `.feb`，从已提交父状态续算才校验并复制父档；删掉尝试目录和求解缓存后仍能重放。
3. **设置五层归属**（场景版本 / 建造配置 / 会话求解设置 / 段 / 一次尝试；归属表见 [建造与粘连规范](../architecture/build-and-attachments.md)）：
   - 按“改它后计算模型变了，还是同模型换步序求解”归属。
   - 质量阻尼 `solver.damping` 进入物理方程，仍归场景物理声明（[ADR-41](ADR-41.md)）。
   - 子步数默认值、数值阻尼 `rhoi`、积分器、迭代与 FEBio 时间步回退移出场景、归会话求解设置，并锁定 FEBio 身份、实际线程数与运行环境（旧场景已有数值按旧优先级迁入并留来源）。
   - 段级覆盖先只开放已通过“同一步序整算对续算”验证的段界步长变化，其余数值设置首版沿用会话值。
   - 加物体、换网格、换粘连算法须新建建造和会话；改场景材料先发布新场景版本再建造并新开会话；仅改建造配置可复用原场景版本。
4. **计算网格边界**：
   - 细四面体网格继续由离线工具生成一次并提交（[ADR-20](ADR-20.md)），建造只按引用加载并核对内容摘要；缺细网格、摘要不符或无有效单元按对象 ID 报错，**禁止在建造或运行时启动 fTetWild，也禁止悄悄回退成粗格子**。
   - 规则格子允许在建造时确定性生成，节点、单元、顺序、参数（含原点）和生成器版本一并封存进建造记录，重放只读封存数组。
5. **现在不定**：
   - 皮肤壳类型和降采样尺度（进入新演示场景建造配置），等同一原始画权重面在两档真实皮肤小片壳网格上对照面积覆盖、局部极值、节点力和最终显示面后再定；
   - 目标图缺失与 envelope 图缺失的近似只允许出现在显式近似配置中且落到受影响的边，等补取外皮目标图与 envelope 图后复核。

## 依据与边界

- **原因**：
  - 现行 `generate.build()` 把静态组织网格、单段运动、FEBio 节点号与 XML 混在一起；建造记录不落盘则换算法无法公平对照、删缓存后无法重放或解释生成器版本差异。
  - 仅有哈希而无实际网格与数组，删档后无法重放；fTetWild 每次结果不同（[ADR-20](ADR-20.md)），规则格子原点位置也会改变嘴唇运动（[ADR-44](ADR-44.md)），必须封存实际数组与全部有效参数。
- **证据（[E-23](../archive/explanations/E-23.md)）**：
  - 源码核实：现行 `generate.py` 在一次 `build()` 中同时决定静态模型与本段运动。
  - 既有实测：fTetWild 同参数不保证逐次相同（[ADR-20](ADR-20.md)）；规则格子平移半格使嘴唇 AA 平均差从 1.883 mm 变到 1.887–2.191 mm、上唇中部从 5.51 mm 变到 4.78–5.55 mm（[ADR-44](ADR-44.md)）。
- **重开条件**：旧建造记录在真实迁移或删档重放中缺少必要数组、配置项或版本信息，导致无法重建等价输入或解释结果差异时，重开建造配置与建造记录的封存范围。

## 历史与修订

- **放弃的方案**：
  - 求解时现找隐式默认配置：代码升级后会悄悄改变已有实验的计算模型；
  - 缺细网格时运行时调用 fTetWild 或自动换粗格：前者破坏复现，后者改变上下唇是否分开的物理行为；
  - 为两种旧嘴唇分写两套旧后端：长期易分歧，合用一份 `legacy-v1` 建造配置更易维护。
