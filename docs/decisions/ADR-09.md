# ADR-09：结果回放用"表面网格 + 点缓存"

| 项目 | 内容 |
|---|---|
| **状态** | ✅ 已定（2026-10-28；2026-11-24 由 [ADR-46](ADR-46.md)、[ADR-52](ADR-52.md) 补充） |
| **关联决策** | [ADR-46](ADR-46.md)、[ADR-52](ADR-52.md) |

## 当前生效结论

- **回放载体**：结果打包成表面网格加每帧点位置文件（PC2 格式），由 Blender 自带的 Mesh Cache 修改器播放。
- **核心公开结果（2026-11-24 补充）**：核心公开结果改为按状态、对象、参考表面、结果层（`physics`/`final`）与绝对帧索引的原序世界坐标数组和结果清单，PC2 为派生的回放文件。
- **回放身份校验（2026-11-24 补充）**：Blender 接回放前不再只核对顶点数，须按参考表面 ID、原始顶点行号、有序静止坐标与连接关系核对身份。

## 依据与边界

- **原因**：Blender 原生支持，不需要每帧重建网格；数据保持毫米，只缩放显示。
- **证据**：`tools/check_playback.py`，逐帧误差小于 0.000001 mm。

## 历史与修订

- **2026-10-28**：定案，采用表面网格加 PC2 点缓存配合 Blender Mesh Cache 修改器播放。
- **2026-11-24（[ADR-46](ADR-46.md)、[ADR-52](ADR-52.md) 补充）**：明确原序世界坐标数组与结果清单为核心公开结果，PC2 定位为派生回放文件，并收紧接回放前的身份校验字段。
