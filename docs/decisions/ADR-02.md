# ADR-02：操作和显示用 Blender

| 项目 | 内容 |
|---|---|
| **状态** | ✅ 已定（2026-10-27；2026-11-24 核实仍生效） |
| **关联决策** | [ADR-45](ADR-45.md) |

## 当前生效结论

- 用 Blender 替换 Maya 作为操作界面。
- 核心程序不依赖 Blender，以后需要的话可以再加 Maya 界面。
- **现状核实（2026-11-24）**：[ADR-45](ADR-45.md) 第 3 条把 Blender 和 Maya 都列为实验室提出的宿主选项，倾向 Blender；产品现在仍不依赖 Maya（`src/`、`blender_addon/` 里没有 Maya 的导入）。

## 依据与边界

- **原因**：免费开源，Python 接口完整，任何人都能装；Ziva 停售以后，Maya 对这个项目已经没有不可替代的价值。
- **放弃了**：继续用 Maya（许可费用，而且原来就是因为 Ziva 才绑定在 Maya 上）。
