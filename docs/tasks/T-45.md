## 目标与范围

- **目标**：用户可将实验室整份演示场景静态导出包导入为 `asrp-scene/2` 场景版本、双向导入台账和场景视图，并在场景视图里点选一条真实的皮肤渐变粘连边、追查它的原始属性和缺失项。
- **输入**：
  - [T-44](T-44.md) 的 `scene` 版本库与场景视图基础设施；
  - 实验室演示场景静态导出数据（仓库外）及仓库内用于无外部数据测试的合成导出包和坏例数据。
- **产出明细**：
  - `importers`（`import_bundle()`：读取独立整数版本的只读静态导出包，产出 `asrp-scene/2` 场景版本、场景视图和双向导入台账）；先把现存只读导出映射成首版导出包，列出来源与缺项，不要求为此重新上机；
  - `scene` 对 `asrp-scene/2` 的对象稳定 ID、参考表面 ID、粘连声明、材料/本构/纤维声明及严格未知字段校验；
  - 本卡新增命令（待实现）：`asrp import-bundle <bundle> --store <dir>`；在 [T-44](T-44.md) 的 `asrp scene inspect` 上加 `--edge <id>`，按边同时给出处、处理状态和缺项；
  - 验收测试 `C03`（待新增）。
- **不做**：不运行 FEBio；不把缺失目标图写成"实验室选了全表面"；不为这张卡重新上机。

## 约束与接口

1. **静态导出包与场景版本（独立整数版本）**：
   - 导出包只读，记导出工具与厂商版本、对象和关系、原始属性、原单位、带原顶点顺序的网格、权重图的索引域、缺失原因和文件摘要。
   - `asrp-scene/2` 为每个对象与参考表面分配改名后不变的稳定 ID；记录参考形状、材料与本构（如 StVK、抗压项、刚度阻尼、Baraff-Witkin 布料模型）、重力与物理尺度、驱动与显示绑定声明（含 4 组 landmark）。
2. **粘连第一层（场景声明，[`ADR-51`](../decisions/ADR-51.md)）**：
   - 每条粘连是独立有 ID、有方向的边，保存源与目标对象及参考表面 ID、源图与索引域、稀疏默认值、目标选区或 `not_exported`、`mode`、`correspondence`、软硬、`maintain_offset`、单位面积刚度（0.1 N/mm³）、`envelope` 及其图缺失状态、阻尼（0.01）及来源。
   - 物理和显示声明的原值、来源、采用值、处理方式都可追查；ID、摘要、长度等管理字段按格式定义。
   - **图画在哪一侧**与**未列元素默认多少**分别记证据（出处 [13 归档 / E-23](../archive/explanations/E-23.md)；多条粘连的 12 对网格中有 8 对参与顶点重叠）：
     - 前者：140 张表里 58 张能按索引排除目标侧，余下 82 张按源侧解释（其中 6 张距离证据反向），逐边标明；
     - 后者：只有演示场景上唇的未列元素取 1 有直接证据，同家族其余边逐边标推断，第二家族待取证。
   - 空的稀疏源表、未导出的目标图、读取失败的 envelope 图必须能分别表示。
3. **纤维与读得懂但不能执行的取值**：
   - 18 个纤维首版**不列为** `asrp-scene/2` 的纤维对象；导出包和台账保留 18 项的身份、所属组织、已知激活、上游连接和方向缺失原因，场景视图可由台账显示这些来源项并标"未参与求解"。
   - 若对应实验全程出现非零激活，或同条件开关纤维出现可辨差异，该实验标"待纤维支持"。
   - 已识别的 `sliding`、`vertexID`、`maintainOffset=false` 和多层材料**可以进入场景版本**，保留原值、来源和"不支持执行"的原因，视图可点选；建造所选范围包含相应边或物体时，生成 FEBio 输入前按 ID 和字段拒绝，显式选择不涉及它们的切片可以建造。
4. **双向导入台账与严格校验**：
   - 台账分两列分别记录"值从哪来"（实验室给的、Ziva 默认值、导入时按规则推的、我们定的）和"程序怎么处理"（已支持、近似、忽略、拒绝），每项原始属性都能追到去处、每条边都能反查原值；分别报告"可读"和"可执行"。
   - 结构由 JSON Schema 管，在可执行声明的每一层拒绝未知字段，未知的可执行字段必须报到具体字段路径；跨对象引用、索引域、摘要、有限数和是否可执行由 `scene` 代码检查，重复键在 JSON 解析时拒绝；v1 仍按旧读取规则。
   - 未知厂商属性留在原包，台账记原位置、可追查引用和"未解释"，不另存一套原始数组。
   - 稳定 ID 由核心生成、使用 ASCII 安全字符，显示名允许 Unicode、空格和重名，引用按 ID。
5. **场景视图**：支持点选一条真实皮肤渐变边，查出其源/目标参考表面、参与顶点、权重、原值及缺失项。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：
  - 运行 `uv run pytest -s -k C03`，调用正式导入与视图查看入口，打印：
    - 演示包导入计数 **41 组织、2 皮肤、10 骨、140 边**；
    - 四类边分布 **`42/36/22/40`**（组织→骨 / 组织→组织 / 皮肤→骨 / 皮肤→组织）；
    - 渐变边 **`49`**（皮肤→骨 19、皮肤→组织 30）；
    - 缺失的目标图、逐顶点 envelope 图与纤维方向；
    - 点选一条真实渐变边反查原值的结果，分别标明的"可读"与"可执行"状态，以及"原包／台账 18，可执行纤维 0"。
  - 未知厂商属性在导出包中原样留存，台账记原位置、可追查引用和"未解释"。
  - 已知但暂不执行的取值（`sliding` 等）能进入场景版本并在视图点选，选中它们的建造被拒绝并报到边 ID 和字段，与未知的可执行字段分别裁定；对象改成中文名、两个对象同名两例中，引用仍指向原对象。
- **必须失败的坏例**：
  1. 权重图里有索引确实超出目标面范围的样本，必须报错并定位到具体边或字段；另做一个两边点数相同但表面 ID 错的合成样本，也必须失败；
  2. 在 `asrp-scene/2` 可执行输入中加入未知字段，必须报错并报到具体字段路径。
- **无外部数据与最终验证**：
  - 无仓库外演示包数据时，真实演示包检查标 `NOT VERIFIED`（`C03` 的真实基线待验，不得据此改冻结点），合成包与全部坏例必须执行通过；
  - 交付最终状态跑 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 现行 `asrp-scene/1` 遇到未知字段报 0 错误 0 提醒（已实测），对象身份只用 `name`，且只能写单块嘴唇。
  - 实验室演示场景实际包含 41 组织、2 层布料皮肤、10 块骨头、140 条粘连边（49 条带小于 1 的渐变权重）、18 个纤维，且目标侧权重图、逐顶点 envelope 图、纤维方向均未导出。
  - 若不先做"只导入不算"的完整试写和双向台账，后面写多物体建造器时会把缺项混成事实（例如把缺失目标图当成"实验室选了全表面"）。
- **现在不定项（等上实验室机器取证）与本卡处理**：
  1. 目标侧选区图与逐顶点 envelope 图（等上机补取）：本卡记为 `not_exported` 并在台账写明缺失原因；
  2. 第二家族场景（无布料训练场景）的稀疏默认值和纤维作用（等第二家族静态导出及上机验证）：本卡只对演示场景上唇应用已有直接证据的稀疏默认 1.0，其余边逐边标推断，不推广到第二家族；
  3. `maintain_offset=true` 的参考点偏移规律（等 Ziva 旋转加拉伸试验）：本卡只原样保留厂商声明，不替它指定偏移规律。
