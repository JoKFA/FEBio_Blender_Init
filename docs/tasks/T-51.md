## 目标与范围

- **目标**：用户可在真实皮肤的原始画权重参考表面上选取含渐变权重、长间距和重叠边的区域，切换两档计算壳网格运行并续算，按稳定表面 ID 分别读回布料面与细显示面的 `physics` 层，并完成逐点面积加权、双向传力和重叠边力矩的独立验证。
- **输入**：
  - [T-49](T-49.md) 的逐点/合并长间距罚约束与诊断；
  - [T-50](T-50.md) 的多物体构建、会话分支与读回；
  - 演示场景中带渐变重叠区域的真实皮肤小片（仓库外）及仓库内用于 2.8 N、反向双边、力矩和坏例验证的合成小片。
- **产出明细**：
  - 壳绑定（原始画权重参考表面到两档计算壳与细显示面）、皮肤粘连边构建与后端写出；
  - `results` 对布料面与细显示面按稳定表面 ID 发布 `physics` 层、对缺资料皮肤 `final` 层显式拒绝；
  - `checks` 对面积覆盖、反法向/漏配、薄单元放大和两档网格对照的报告与校验；
  - 验收测试 `C09`（待新增）。
- **不做**：不重画权重、不跨边合并、不静默回退 `tied`；不发布缺资料的皮肤 `final` 层。

## 约束与接口

- **原始画权重面面积加权与两档计算壳**：
  - 在原始画权重参考表面上（先转物理毫米）保留每个参与点的面积（相邻参考三角形面积 1/3）和逐点对应，**不重画权重**。
  - 同分辨率壳直接取节点，粗壳用该原始画权重点的绑定；首试使壳参考面与画权重参考面重合，记录壳中面、正反面和法向约定；先在已有续算证据的 **ANS 壳**上验证，并对同一画权重面和相同边界条件跑两档计算壳网格。
- **独立力学裁判（经正式生成入口；合成手算与真实两档壳分栏报告）**：
  - 两个点面积 1 与 9、权重 1 与 0.2、单位刚度与 1 mm 位移：逐点面积加权总反力必为 **`2.8 N`**（[E-23](../archive/explanations/E-23.md)）；
  - 两条独立边反向拉（+2 mm 刚度 0.1 对 −2 mm 刚度 0.2）：平衡位置必为 `−2/3 mm`（**`−0.6667 mm`**，同上），按运行前登记的容差判；
  - 同一目标物体上两个不同落点的双边：转动目标物体，由已知力和当前位置独立算力矩并核对，故意把两个落点并成一个必须失败，防止错误合并把力移到错位置；
  - 合成门限只适用于合成小片；真实小片的时间收敛和研究可用性另行判断。
- **结果层与皮肤→骨边界（[`ADR-52`](../decisions/ADR-52.md)）**：
  - 布料面（若作为实验室读取面）与绑定的细显示面用**不同稳定表面 ID** 发布 **`physics`** 层；粗壳若仅为内部网格，其节点数组归诊断。
  - 皮肤 `final` 层（"最终嘴唇 → 包裹曲线 → 皮肤蒙皮"）在缺数据或未验证前**绝不发布**，清单写明原因、请求读取皮肤 `final` 必须报错失败。
  - 本卡不含皮肤→骨边：刚体目标上的逐点约束尚无卡承接，未试验前标未支持；若所选小片的选区需要皮肤→骨边，须换成范围清楚的组织目标小片，不得静默漏边；缺曲线资料时比较已支持的细面 `physics`，皮肤 `final` 继续标缺。
- **整算/续算、放大指标与独占分项计时**：
  - 完成整算与运动中续算对照（位置 `1e-5 mm`、速度 `1e-4 mm/s`、应力 `1e-6 MPa`）。
  - 逐边报两档面积覆盖、分方向位移与反力、力矩、局部极值、最大 `|βⱼ|`、`Σ|βⱼ|` 及合并前后的点数/行数/内存。
  - **计时期间独占 FEBio**，分项记录建造、求解、存档、结果写出、首帧可见和整段可读耗时；粘连阻尼 0.01 明确标"未施加粘连阻尼"。
- **官方算例参考（[07 第 1.2 节](../07-validation.md)）**：对实际支持的壳构型补对应的 FEBio 官方算例参考；没有同物理能力的官方算例时列明缺口，用本卡的独立手算裁判，不把原样跑通算作生成器通过。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：
  - 运行 `uv run pytest -s -k C09`，经正式入口完成力学裁判与两档壳小片运行。
  - 打印：手算 `2.8 N` 实测值、反向双边平衡 `−0.6667 mm`、同目标不同落点的力矩校验、两档壳的面积覆盖与局部极值、薄单元外推放大指标、整算与续算误差，以及独占 FEBio 的分项计时。
  - 两档壳逐一列覆盖面积、漏配和极值，合成手算与真实小片分栏打印。
- **必须失败的坏例**：
  1. 改用组平均面积算出 `6.0 N`，裁判必须失败；
  2. 壳反法向漏配，或只配上半张面（覆盖检查），检查器必须报出缺口并失败；
  3. 请求读取缺资料的皮肤 `final` 层，必须明确失败并给出清单原因；
  4. 跨边合并或静默回退 `tied-elastic`，必须被检查拒绝。
- **无外部数据与最终验证**：
  - 无仓库外真实演示数据时，真实皮肤小片部分标 `NOT VERIFIED`（`C09` 的真实部分待验，不得据此改冻结点），合成力学裁判与全部坏例必须执行通过；
  - 交付最终状态跑 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 演示场景中 49 条带小于 1 渐变权重的粘连边全部以皮肤为源（30 条皮肤→组织、19 条皮肤→骨头），且 8 对参与顶点重叠的网格对里有 6 对源是外层皮肤（同一顶点最多同时参与 3 条粘连，[13 归档 / E-23](../archive/explanations/E-23.md)）。
  - 嘴唇权重全为 1，嘴周切片也不含皮肤，只有真实皮肤小片才能检验渐变权重面积积分、重叠边力矩、粗壳到细显示面绑定和薄单元外推放大。
  - 已知 EAS 壳续算会崩溃、皮肤壳法向反了时 FEBio 只写警告却正常结束且皮肤没粘上（[05](../05-ziva-to-febio.md) / [FEBio 已知坑](../05-febio-pits.md) 坑 21、[E-22](../explanations/E-22.md)）。
  - 渐变边里，30 条皮肤→组织目前只有目标侧机制的合成证据，真实壳源等本卡；19 条皮肤→骨还需要刚体偏心传力试验（尚无卡承接）。
- **本卡涉及的现在不定项及当前做法**：
  1. 皮肤降采样尺度与三角壳最终类型（等本卡两档真实皮肤小片对照数据）：本卡先用 ANS 壳做两档测量并报告，不硬定最终尺度；
  2. 粘连阻尼 0.01 的换算（等上机同条件衰减对照）：本卡弹性试验标"未施加粘连阻尼"；
  3. 参考点偏移规律（等 Ziva 旋转加拉伸试验）：本卡用已验仿射外推纯罚，超已验证放大范围标"未支持"，不静默退回 tied；
  4. 目标选区图和逐顶点 envelope 图（等优先补取外皮渐变重叠边）：本卡显式按近似配置运行并逐边落账；
  5. 刚体目标逐点约束（尚无卡承接）：本卡不含皮肤→骨边，见结果层与皮肤→骨边界；
  6. 合并是否默认启用（等本卡与 [T-50](T-50.md) 实测统计原点数、不同支撑组数、写出行数、峰值内存和耗时）；
  7. 罚约束在动力学里的时间精度（[T-49](T-49.md) 的四项取证）：任何一项不过，这条实现就不用于本卡带动力学的签收；两条反向边的平衡与同一目标不同落点的力矩由本卡（`C09`）验，[T-49](T-49.md) 只验单条边，两组不能互相抵账。
