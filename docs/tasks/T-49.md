## 目标与范围

- **目标**：用户可运行包含长间距软粘连的合成双组织场景，经正式 `build`、`backends/febio`（含逐点与按单元对精确合并两种写出）和 `results` 读回两侧物体结果，并按边 ID 查清逐点对应、外推系数放大指标与后端约束实现记录。
- **输入**：
  - [T-46](T-46.md) 的 `build` / `backends/febio` / `checks` 骨架与 [T-48](T-48.md) 的完整会话续算与原子提交；
  - 合成双组织长间距场景（如 15 mm 间隙、目标四面体外推与对照配置）。
- **产出明细**：
  - `build` 内的逐点对应与面积加权刚度计算、外推系数与单元质量诊断报告；
  - `backends/febio` 的纯罚线性约束逐点写出与按单元对 QR 等价合并写出、实现记录及世界方向落点对照（世界方向线性行与 FEBio `tied-elastic` 分别命名，并保留独立的 `tied-elastic` 对照）；
  - `checks` 对 `<laugon>` 标签、退化单元、远端力/力矩平衡和合并等价性的核验；
  - 本卡新增命令（待实现）：
    - `asrp build inspect <build-record> --edge <id>`（查某条边的实际约束，与导入时查原值分开）
    - `asrp results read <results.json> --object <id> --surface <id> --layer <name> --frame <n> --out <file.npy>`
  - 验收测试 `C07`（待新增）。
- **不做**：不许动场景里的厂商声明、旧嘴唇实现、逐点证据；不得把结果外推成刚体目标或 Ziva 等价结论。

## 约束与接口

- **建造中的逐点对应（[`ADR-51`](../decisions/ADR-51.md)）**：
  - 新粘连面积在物理毫米坐标中计算（参考面若已是几何毫米，物理面积 = 几何面积 × `physics_length_scale²`，只换算一次，结果仍按几何毫米读回；`legacy-v1` 直接读已存 N/mm），逐顶点面积取相邻参考三角形面积的 1/3，算每点刚度 `kᵢ = K × Aᵢ × wᵢ × eᵢ`（N/mm，须非负）。
  - 在每条边指定的目标物体与选区内找落点 `q₀`（记录参考三角形、面内重心坐标、`g₀ = p₀ − q₀`）；**支撑四面体从目标落点 `q₀` 的显示绑定选**（不得直接在空间找离 `p₀` 最近的四面体，以免选错组织）。
  - 在目标四面体中算重建 `p₀` 的外推重心系数 `β`（源侧算到源四面体的 `α`），显式记录采用的参考点规律（本卡首试仿射外推，同时保留按落点算 `β` 的世界方向配置作对照）。
  - 逐边报告 `|g₀|` 分布、支撑单元厚度或质量、最大 `|βⱼ|`、`Σ|βⱼ|` 和受影响面积；**退化单元直接拒绝，严禁剪掉负系数**。
- **FEBio 后端逐点写出与强制校验**：
  - 软约束必须写在 `<Constraints>` 下的 `linear constraint`，显式写入 `<laugon>0</laugon>`、实际 `<penalty>` 和 `<rhs>0</rhs>`，不得写入 `<Boundary>` 消元，不得省略 `<laugon>`。
  - 原因：本机实测不写 `<laugon>` 默认增广拉格朗日，0.1 N 位移变成 `7.5×10⁻⁸ mm` 而非 `0.2 mm` 且无警告（[E-23](../archive/explanations/E-23.md)）。
- **按单元对的 QR 等价合并（放后端，[`ADR-51`](../decisions/ADR-51.md)）**：
  - 对同一边、同一有序支撑自由度组内固定系数、零右端、各向同性、非负 `kᵢ` 的纯弹性罚约束，取固定参考刚度 `k* = 1 N/mm`，令 `Dᵢ = √(kᵢ / k*) aᵢᵀ`（同一全局节点重复先相加），做 `D = QR` 分解，把 `R` 写成系数、罚系数写 `k*`（4+4 平移节点时每轴至多 8 行，原不足 8 行保留原行；不删给定自由度；不跨边合并）。
  - 记录实际写出行数、系数精度、版本和逐点回溯关系；**保留逐点模式作裁判**，对**写出再读回的系数**核对整块矩阵 `K` 与逐节点恢复力 `-KU`，并跑同一载荷和运动中续算对照。
- **独立力/力矩核对**：
  - 已知 FEBio 4.13 的约束力不出现在被给定位移的目标节点 `Rx` 里（合计为 0），且 `zero displacement` 不记反力、`Rx` 与支座力反号（[E-23](../archive/explanations/E-23.md)）。
  - 验收必须使用已知外载与**未参与约束的远端支座**（先校准反力符号），并逐点用 `cᵢ` 重建源侧 `-kᵢ α cᵢ`、目标侧 `+kᵢ β cᵢ`（注明符号、单位和取矩位置）。
- **动力学取证（必做并报告，不是本卡通过的条件）**：
  - 判据在运行前登记，结果写进 `docs/archive/explanations/`（与 [E-23](../archive/explanations/E-23.md) 同处）的新条目：固定驱动下逐级减小时间步，比位移、相位、峰值和衰减；多个切点；1 和 4 线程；源节点被给定位移。
  - 四项里任何一项不过，这条实现就不能用于带动力学的签收（[T-51](T-51.md)）。
- **官方算例参考（[07 第 8.2 节](../07-validation.md)）**：对实际支持的接触类型补对应的 FEBio 官方算例参考；没有同物理能力的官方算例时列明缺口，用本卡自己的独立手算裁判，不把原样跑通算作生成器通过。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：运行 `uv run pytest -s -k C07`，经正式入口跑合成双组织长间距场景并读回两侧结果与边实现记录，打印：
  1. 三轴已知小力下的位移 `F/k = 0.2 mm`（0.1 N / 0.5 N/mm）；
  2. 目标沿间距方向拉长 10% 后的间距 `16.5 mm`（仿射外推判据）；
  3. 未参与约束的远端支座力平衡与按源点位置取矩的力矩平衡（附反力符号校准）；
  4. 逐点力学与 QR 写出等价分开报：先复跑三轴刚度、旋转、伸长和远端力矩，再用点数足够多、QR 真正压缩的同一组支撑，对写出再读回的系数打印整块矩阵误差、每节点恢复力误差、实际写出行数，并跑同载荷和续算（数值容差在运行前登记）；
  5. 运动中续算与整算的逐帧位置、速度、应力误差（对照 `1e-5 mm` / `1e-4 mm/s` / `1e-6 MPa`，运行前登记）。
- **必须失败的坏例**：
  1. 删去 `<laugon>0</laugon>` 或改成 `<laugon>1</laugon>`，XML 检查与 `0.2 mm` 独立裁判必须抓住并失败；
  2. 在合并矩阵里故意翻转一列节点系数符号，矩阵与节点力裁判必须失败；
  3. 把外推参考点换成目标表面落点（世界方向），15 mm 力臂下 `0.1 N` 横向载荷出现约 `1.5 N·mm`（试验实测 `1.50000001 N·mm`，[E-23](../archive/explanations/E-23.md)）力矩不平衡与 15° 旋转 `3.9158 mm` 偏移，相应裁判必须抓住；
  4. 物理长度尺度取 0.67（不是 1）时，面积若按几何毫米算，刚度总量会差 `0.67²` 倍，裁判必须抓住并失败（单位尺度下的 `2.8 N` 例抓不到这个错）。
- **门禁验证**：交付最终状态跑 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 演示场景绝大多数粘连隔着几毫米到几厘米（组织→组织中位 3.2 mm、最大 60.7 mm；皮肤→组织中位 8.1 mm、最大 34.7 mm），且 49 条皮肤渐变边需要逐点给刚度。
  - 已实测 FEBio 的 `tied-elastic` 一条界面只有一个罚系数，且在 15 mm、15° 旋转下与"跟着转"差 `3.9158 mm`（[E-23](../archive/explanations/E-23.md)）。
  - "目标四面体外推参考点 + 纯罚线性约束"已在本机合成探针上通过事先登记的 9 项试验（单线程、一个运动中切点，比位置、结束时间和帧范围）；位置、速度、应力三项门限的预登记检查另见三块组织的会话试验，不能记成这条新罚约束已三项通过（[E-23](../archive/explanations/E-23.md)）。
  - 按单元对的 QR 等价合并已通过矩阵算术复算（32 行合并为 8 行，一次观测误差 `1.42e-14`，只算矩阵、没有跑过运行），但尚未经正式生成器实跑，也须用检查锁住省略 `<laugon>` 等已发现的坑。
- **本卡涉及的现在不定项及当前做法**：
  1. 真实 Ziva 的参考点规律（等 Ziva 旋转加拉伸试验）：本卡只实现并验证仿射外推与世界方向对照，不把仿射写成 Ziva 定律；
  2. 薄单元外推系数的统一可接受阈值（本机实测最大系数 `150.5` 时，目标节点 `0.01 mm` 误差在源点放大为 `−1.5 mm`，[E-23](../archive/explanations/E-23.md)）：
     - 阈值等真实切片 [T-50](T-50.md)/[T-51](T-51.md) 测量；本卡逐边报告最大 `|βⱼ|`、`Σ|βⱼ|`、单元厚度/质量与面积，直接拒绝退化单元，不剪负系数；
  3. 合并是否默认开启（等真实模型 [T-50](T-50.md)/[T-51](T-51.md) 统计点数、行数、内存和求解时间）：本卡提供逐点与合并两种模式，保留逐点作裁判；
  4. 罚项在动力学里的时间精度（源码未乘广义 α 系数）：见约束中的四项动力学取证，不是本卡通过的条件，但任何一项不过，这条实现不能用于带动力学的签收；刚体目标上的逐点约束尚无卡承接，本卡不涉及；
  5. 两条反向边的平衡、同一目标不同落点的力矩归 [T-51](T-51.md)（`C09`）；本卡验**单条**长间距边在已知横向载荷下的远端力和力矩，以及把外推换成表面落点必须失败，两组不能互相抵账。
