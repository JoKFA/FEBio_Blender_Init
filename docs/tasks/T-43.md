## 目标与范围

- **目标**：通过正式命令 `asrp run <scene> <motion> --threads 1` 把现有两种旧嘴唇场景和"只改材料、未改旧弹簧刚度"的样本封存成独立的本地基线与比较器，使后续迁移（[T-44](T-44.md)、[T-46](T-46.md)）能自动抓住数值漂移、旧弹簧被重算或坐标行错位。
- **输入**：
  - 现行可运行的 `asrp run` 命令行入口；
  - 本机实验室嘴唇资产及真实运动（位于仓库外，由 `.local/` 或环境变量定位）：覆盖 `ours`（上唇硬）、`ziva-soft`（四组全软），以及一份只改材料、未改旧弹簧 N/mm 的样本；
  - 用于仓库内无外部数据时也能跑通比较器逻辑的合成基线输入。
- **产出明细**：
  - 本地基线采集脚本/逻辑与独立比较器（核心坐标几何毫米比较与 PC2 float32 读回精度比较分开）；
  - 本机封存的基线记录（敏感样本和原始运行结果留在仓库外原处，不进 git；仓库内只保存合成输入与检查逻辑）；
  - 验收测试 `C01`（待新增）。
- **不做**：不许动生成器、导入器、默认设置、既有输出。

## 约束与接口

1. **正式采集与完整封存**：
   - 用正式入口 `asrp run <scene> <motion> --threads 1` 分别运行"上唇硬"、"四组全软"以及"只改材料、保留旧弹簧 N/mm"三份样本。
   - 记录完整输入标识、运行环境（FEBio 版本、Python 版本、线程数）、帧数与点数、`physics` 与 `final` 层数组摘要，以及 PC2 读回误差。
   - 原始数组、有效输入和环境一并封存；摘要只用来查损坏，不代替封存的数组。
   - 必须显式指定 `--threads 1` 封存基线：原型粗格子中性到 AA 的一次配对试验里，1 线程下同一份输入跑两遍逐字节相同，4 线程下两遍之间相差约 `1×10⁻¹² mm`（日志坐标口径；不承诺任意模型、任意输出文件逐字节一致，条件见 [13 归档 / E-23](../archive/explanations/E-23.md)）。
2. **独立比较器口径（[`ADR-48`](../decisions/ADR-48.md)）**：
   - 在同环境、同驱动、同帧、同点口径下，对核心几何毫米坐标执行 `1e-9 mm` 迁移门限检查并报最坏帧、点、分量。
   - 对 PC2 点缓存按该帧 float64 参考转成 float32 后的值单独核对，不把 PC2 混入 `1e-9 mm` 门限。
3. **敏感数据与缺数据规则（[08](../08-engineering-standards.md) 第 5、8 节）**：
   - 实验室敏感样本留在仓库外原处，仓库外原始资产和运行结果不得进 git；文档和测试中不写只属于一台机器的路径或用户主目录（第 6 节）。
   - 三份真实样本缺任何一份，`C01` 的真实基线就标 `NOT VERIFIED`（待验），不得据此把相应冻结点改成已过；合成输入和坏例检查照常执行。
   - 同一规则适用于 `C03`、`C08`、`C09` 的真实数据和各自的冻结点。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：
  - 运行 `uv run pytest -s -k C01`，真实调用 `asrp run <scene> <motion> --threads 1` 与独立比较器。
  - 打印三份样本的输入标识、运行环境与实际线程数、帧数和点数、`physics` 与 `final` 层摘要、PC2 读回误差，以及旧基线重读通过的结果。
- **必须失败的坏例**：
  1. 修改样本里一项**实际生效**的旧弹簧刚度（N/mm），比较器的输入比较必须失败并指出该项；
  2. 在有载荷、位移不同的点上交换两行**不同**的顶点坐标，比较器必须失败（两行本来相同，就不能靠坐标判交换）。
- **门禁验证**：
  - 开发过程跑 `uv run python tools/verify.py --level core`；
  - 交付最终状态跑 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 现有旧嘴唇导入器能产出"上唇硬、其余三组弹簧"（`ours`）和"四组全软"（`ziva-soft`）两种旧嘴唇场景，且现行代码里手改场景材料不会重算落盘的弹簧刚度（[`T-37`](../archive/tasks/T-37.md) 第 15 项）。
  - 核心坐标是 float64，而给 Blender 回放的 PC2 点缓存是 float32。
  - 不在切开生成器前把这三份旧行为封存成独立基线和裁判，后续重构生成器或迁移 `asrp-scene/2` 时就无法证明"旧实验没有被暗中改掉"。
