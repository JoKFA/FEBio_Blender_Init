## 结论与现状

- **进展（2026-11-15，[ADR-44](../decisions/ADR-44.md)）**：
  - 格子办法已做成产品里第二个可选的网格 `data/tetmesh/lips_lattice.json`（126 个四面体，格边 = Ziva 的 `tetSz` 换算成 25.37 mm，原点 = 表面包围盒最小角，上下唇**不**分开，文件里写明）。
  - 生成命令：`uv run python tools/build_tetmesh.py --method lattice`，有自己的检查 `tetmesh.check_lattice`，生成两遍哈希相同。
  - **代价与好处**：代价是上下唇是一个整体；好处是在实验室的 AA 上上唇被带动（5.5 mm，Ziva 4.80），细网格几乎不动（0.22 mm）。
  - **默认选用（[ADR-44](../decisions/ADR-44.md)）**：项目负责人已定，面板默认用粗格子，`asrp import-asset` 命令行不加选项时仍是 `lips.json`。
  - **未做部分**：
    - 上面"同一格里上下唇不相连的部分各自成格"这一点**没有**做（684 个四面体的试验里它让上唇不动，[ADR-42](../archive/decisions/ADR-42.md)）；
    - 比较报告写进 [13](../13-explanations.md) 的 [E-03](../archive/explanations/E-03.md) 和 [11](../11-risks-and-questions.md) 的 A-32 仍待做。

## 目标与范围

- **目标**：做一个和 fTetWild 并排比较的备选生成办法：用整齐的格子罩住嘴唇表面，保留在实体内部的格子；同一格里上下唇不相连的部分，各自成格（各算各的）。
- **为什么**：
  - 现有办法（fTetWild，[ADR-20](../decisions/ADR-20.md)）每次结果不同、偶尔崩溃、会出极小的四面体，还依赖锁了版本的第三方包；
  - 格子办法是确定的、不怕表面自相交，Ziva 自己就是这类做法。网格已经是独立的文件，换生成办法不影响下游。详见 [13](../13-explanations.md) [E-03](../archive/explanations/E-03.md) 末尾。
- **触发时机**：和 [T-17](../archive/tasks/T-17.md)、[T-23](../archive/tasks/T-23.md)、[T-24](T-24.md) 三个试验一起做，在第二阶段投入之前。[T-06a](../archive/tasks/T-06a.md) 的运行没有出现嘴角小四面体的问题（0 次重试、没有负体积），所以不是为了救急。
- **不做**：换掉现有网格（换不换由项目负责人看报告决定）；改下游。

## 关键规格与约束

- **做法**：生成的网格过 `asrp_core.tetmesh` 同一套检查和同一个 FEBio 重力沉降测试（`tests/s2_lips_febio.py`），再和 `data/tetmesh/lips.json` 并排比较三项：
  - 结果（下沉量、嘴缝宽度、嘴角处的行为）；
  - 速度；
  - 稳定性（重复生成是否逐位相同、有没有极小的四面体、有没有崩溃）。

## 验收条件

- 同样的输入重复生成，网格逐位相同；
- 通过 `tetmesh.check` 全部检查；
- FEBio 重力沉降测试正常结束；
- 报告有上面三项比较，并给出明确结论（换 / 不换 / 并存）。
