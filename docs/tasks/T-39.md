## 目标与范围

- **目标**：研究员在 Blender 里对自己选中的网格做 Ziva 在 Maya 里的三个动作：标成骨头、标成软组织、去掉物理；标成软组织时生成四面体；粘连在面板上列出来并能改。研究员在 Blender 标角色和编粘连，编辑经核心发布新场景版本，`.blend` 保存仓库与版本引用；存盘再打开一切还在。
- **为什么**：原型机的资产是固定的一套，角色、四面体、粘连都是事先定好的，面板上只读（[06](../06-ui.md) 第 3.2 节）。实验室在 Ziva 里是自己标、自己搭的（[14](../14-ziva-demo-walkthrough.md) 第 1 节第 7 到 9 步）。最终产品的流程对照表在 [01](../01-overview.md)"最终产品是什么形状"。
- **不做**：钢琴界面和控制器（实验室的）；整张脸的其余组织（第二阶段）；在 Blender 里改材料模型。

## 关键规格与约束

- **依据**：
  - [01](../01-overview.md) 的对照表；
  - [04](../archive/prototype/04-v1-architecture.md) 第 5.1 节（场景描述）、[场景与数据](../architecture/scene-and-data.md)（原 04 第 13.4 节，场景版本的落盘、引用与保留）；
  - [ADR-44](../decisions/ADR-44.md)（粗格子四面体是确定的、不依赖第三方网格工具，适合在标记时现场生成）；
  - [06](../06-ui.md) 第 3.1 节的设计原则。
- **做法**（开工前先写成设计，交项目负责人看过）：
  1. 场景的真身是核心发布的场景版本：研究员在 Blender 标角色和编粘连，编辑经核心发布新场景版本，`.blend` 只保存仓库与版本引用（身份与引用用 [T-44](T-44.md)，建造能力用 [T-46](T-46.md)）；
  2. 标成软组织时用规则格子生成四面体（`asrp_core.tetmesh` 的格子生成，[ADR-44](../decisions/ADR-44.md)），面板写出个数、格边和存在哪；细网格仍然只能事先生成（fTetWild 每次结果不同，[ADR-20](../decisions/ADR-20.md)）；
  3. 粘连：先支持"离得近的顶点自动连上"和手选顶点两种来源，列在面板上，可以高亮、删除；实验室的粘连是怎么生成的还没有答案（[11](../11-risks-and-questions.md) 的 Q18），答案回来以前不猜它的规则；
  4. 骨头的运动来源（固定、跟着哪个驱动）在面板上选。

## 验收条件

- 一位没参与开发的人，从一个只有网格的 `.blend` 出发，不看命令行，搭出嘴唇加下颌的场景并跑通一段运动；
- 搭出来的场景和导入得到的场景在同一段运动上结果相同（同一种四面体、同样的粘连顶点时，逐帧差在容差内）；
- 存盘、关掉、再打开，场景和结果都在；
- `uv run python tools/verify.py` 通过。
