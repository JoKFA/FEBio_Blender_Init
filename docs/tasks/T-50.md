## 目标与范围

- **目标**：用户可通过正式入口运行包含 11 块组织、2 块骨头、22 条粘连边的真实嘴周切片，在运动中途分支，并通过 Blender 与数组读取器按对象和参考表面分别取回结果；同时量出真实切片的局部转角、伸缩、外推系数与合并统计。
- **输入**：
  - [T-45](T-45.md) 导入的演示场景版本（从中切出 11 组织、2 骨、22 边嘴周切片，仓库外数据）及仓库内合成多物体（含间接连骨与两个同点数对象）测试数据；
  - [T-48](T-48.md) 的完整会话分支与恢复能力；
  - [T-49](T-49.md) 的长间距软粘连构建、后端写出与检查。
- **产出明细**：
  - 多物体 `build`（支持多组织、多骨、多条组织边与沿用旧嘴唇硬绑定或弹簧的组织→骨边）、多物体 `backends/febio` 写出、多物体 `results` 读回与 Blender 逐对象加载集成；
  - 新演示建造配置 `demo-v1`（待实现）：允许近似的边和具体近似展开，由用户显式选择，配置名本身不授权补缺图；
  - 嘴周切片逐边覆盖、间距、目标局部旋转伸缩、外推系数与合并统计报告；
  - 验收测试 `C08`（待新增）。
- **不做**：不改完整场景去补偿切片边界；不以嘴周切片签收皮肤权重。

## 约束与接口

1. **多物体建造与显式近似**：
   - 在演示场景中切出嘴周 11 块组织（嘴唇 + 嘴周 6 块肌肉 + 2 块嘴角小组织 + 嘴角小组织后面、连向颅骨和下颌的 2 块组织）、2 块骨头（颅骨、下颌）、22 条粘连边（约 3,800 个参与顶点，按各自 `tetSize` 规则格子包围盒上限约 600 节点），**不改动完整场景来补偿切片边界**。
   - 针对未导出的目标侧权重图与逐顶点 envelope 图，在建造配置里显式开启近似（在每条边**指定目标**全参考表面找最近点、缺失 envelope 暂取 1）并落到受影响的 22 条边；开算前先列出 22 个预期边 ID，每条写实现、依据、覆盖面积和不适用项。
2. **组织→骨边边界**：
   - 嘴周切片包含组织→骨头边；刚体目标上的逐点约束尚未独立验证（尚无卡承接），本卡的组织→骨边沿用旧嘴唇的硬绑定或三向弹簧实现（`legacy-v1`），逐边标近似，并要求每条边能用独立的小算例证明适用。
   - 达不到的边报告该边阻塞，不拿旧嘴唇或可变形目标的证据代签，也不隐式外推刚体逐点约束。
3. **运动中分支与多物体读回**：
   - 从运动中状态开出两条分支，经 Blender 插件和数组读取器按"状态、对象、参考表面、`physics` 层、绝对帧"逐对象取回顶点并校验身份（包括由给定运动驱动的骨头）。
   - 多物体读回按 `asrp-results/1` 清单（`results.json`）验对象、表面、层和绝对帧的对应。
4. **实测局部量与合并收益**：
   - 逐边记录覆盖、间距分布、目标支撑四面体的局部转角、伸缩、单元厚度/质量、最大 `|βⱼ|`、`Σ|βⱼ|`、受影响面积，以及合并前后的原点数、不同支撑组数、写出行数、峰值内存和耗时。
   - 目标四面体的旋转、伸缩和 `β` 只报给确有这种支撑的边。
5. **参照标注**：如并排展示全脸 Ziva 轨迹，必须明确标为"边界条件不同的参照"（同一 Ziva 同一运动仅关掉其余 42 个物体，第 36 帧嘴唇就改变平均 1.98 mm、最大 7.98 mm），绝不当通过线。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：
  - 运行 `uv run pytest -s -k C08`，经正式入口跑嘴周切片（及仓库内合成多物体场景）、运动中分支并在 Blender 与数组读取器逐对象取回。
  - 打印：11 组织、2 骨、22 边的逐边覆盖、间距、目标局部旋转与伸缩、逐对象读回身份（对象 ID、参考表面 ID、`physics` 层），以及两条分支上已知非零运动点的数值；全脸 Ziva 轨迹（若输出）须显式标为"边界条件不同的参照"。
- **必须失败的坏例**：
  1. 断开中间一条实现间接连骨的边：预期边清单检查和已知受力路径上的非零响应（不只看位移）都必须抓住并失败；
  2. 对调两个顶点数相同的对象，身份校验必须失败；
  3. 实现记录或覆盖检查漏报 22 条边中的任意一条，必须失败。
- **无外部数据与最终验证**：
  - 无仓库外真实演示数据时，真实嘴周切片部分跳过并打印 `NOT VERIFIED`，合成多物体与全部坏例必须执行通过；
  - 因涉及 Blender 读回集成，交付最终状态跑全量 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 现有代码在生成器、运行、回放、Blender 插件四处写死了"正好一块软组织"（[E-21](../archive/explanations/E-21.md)），原型把嘴周 6 块肌肉和经别的组织间接连骨的关系简化成了单个嘴唇加锚。
  - 嘴周切片是从真实演示场景切出的最小多物体闭环，能验证两侧不对齐网格的真实组织→组织连接、间接连骨、多物体分支与逐对象读回。
  - 同时还能直接量出组织支撑四面体在真实下颌转动（84 份运动中 46 份动下颌，最大 6.65°，[13 归档 / E-23](../archive/explanations/E-23.md)）下的局部转角和伸缩，替代仅靠下颌角做的上界估算。
- **本卡涉及的现在不定项**：参考点规律（等 Ziva 旋转加拉伸试验）、目标选区与 envelope 图（等上机补取）、刚体目标逐点约束（尚无卡承接；本卡的组织→骨边沿用旧嘴唇的硬绑定或弹簧）、合并是否默认启用（由本卡和 [T-51](T-51.md) 实测数据共同决定）；在证据补齐前，本卡严格使用显式标注的近似配置。
- **上界说明**：用下颌最大转角估出的间距偏移上界，只在假定局部同角、取间距垂直于转轴的分量时成立；不得据此给任何一条组织边签精度，本卡以实测的局部量为准。
