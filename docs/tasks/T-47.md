## 目标与范围

- **目标**：用户可通过正式会话入口新建会话、提交初始化段（纯重力沉降或非中性起步），再显式指定父状态追加第二段运动并读出接头前后两帧；在同一起点、同一实际驱动样本和相同步序下，分段续算与从头整算在登记容差内一致。
- **输入**：
  - [T-46](T-46.md) 的不可变建造记录、编号表与 `checks`；
  - 实验室或合成两段连续运动（覆盖"首段静止、次段动下颌"及"非零通道下段省略"）。
- **产出明细**：
  - `motion` 模块（`resolve(parent_controls, segment)`：识别起步/追加/保持/复位，单位转换与插值，分离物理通道与显示通道）；
  - `sessions` 模块基础目录与操作（`session.json`、`build/`、`states/<state-id>/`、`cache/<state-id>/`、`attempts/<attempt-id>/`、`refs/`；`create()`、`advance(parent, segment)` 等）；
  - `backends/febio` 首段 `.feb` 与续算 `.rst`（加 `-noappend`）写出及按绝对物理时间读回结果；
  - 本卡新增命令（待实现，根也有明确的 ID）：
    - `asrp session create <revision> --store <dir> --profile <profile> --out <dir>`
    - `asrp session advance <session> --parent <state> --segment <file>`
  - 每段数组按对象、表面、层分别存 float64 `.npy`；新段头用 `asrp-display/3`（待实现，旧 `asrp-display/2` 照旧读），首行可对应任意已发布的绝对帧，并与结果清单互验；
  - 验收测试 `C05`（待新增）。
- **不做**：不许动已锁定的建造、已经发布的样本、旧整段插值语义。

## 约束与接口

- **会话新建与起步（[`ADR-49`](../decisions/ADR-49.md)）**：
  - 根状态为参考姿态、零时刻和明确初始控制量；新建时锁住场景版本、建造记录、FEBio 可执行文件身份、相关库与线程设置。
  - 从根提交初始化段，支持纯重力沉降与第 0–14 帧非中性起步；仅在满足原有静止检查时标"已沉稳"，非中性起步无纯重力沉降区间时记录"不适用"和原因且不标"已沉稳"；随后接段绝不自动补沉降或末尾保持。
- **追加与缺省通道语义**：
  - 显式指定父状态（`motion` 读取父段末控制量，不读 `.dmp`）；父末帧 `f` 归父，子段发布 `(f, f+n]`，输入包含 `f` 作接头。
  - 省略已声明通道表示**保持父末值**，回零必须显式给出；接头控制值与父末不符时报错并指明通道，突变须写成有时间含义的动作；未知非零通道报错；物理通道样本与显示通道输入（如 landmark）一并封存。
- **插值规则（[`ADR-54`](../decisions/ADR-54.md)）**：
  - 新会话默认分段线性；旧整段平滑（单调三次 Hermite）显式保留。
  - 显式要求平滑的新段只使用该段已知关键帧及父末值，端点用单侧规则，一次生成即封存，不承诺接头速度连续；**首版段格式不要求端点速度**。
- **续算写入、时间读取与段级设置**：
  - 首段写 `.feb`、追加写 `.rst`（共享建造编号表，采用 `-noappend` 并在正式入口核验）；两阶段整算对照须把两阶段均写成 `Step`（已知坑：顶层 `Control` 后写普通 `Step` 会替换顶层 `Control`，见 [13 归档 / E-23](../archive/explanations/E-23.md)）。
  - 读取器必须按**绝对物理时间**匹配帧（已知坑：FEBio 续算后步数从 1 重新数，按步号会叠帧）；生产检查必须先查看**全部实际时间**再筛期望帧，不可照抄旧试验脚本先筛帧再查的做法（[E-23](../archive/explanations/E-23.md)）。
  - 段级覆盖先只开放已验证的段界换步长，迭代上限、数值阻尼等首版沿用会话值；追加后第一次续算就用独立的父档副本（破坏性恢复验证归 [T-48](T-48.md)）。
- **补齐第 2 类用例与旧入口切换（[`ADR-48`](../decisions/ADR-48.md)，第 13.13 节）**：
  - 先静后动与省略保持：运行三段（两块骨头都静止 → 驱动其中一块 → 省略已非零的通道），对照使用相同实际样本和步序的整算（续算门限单列：位置 `1e-5 mm`、速度 `1e-4 mm/s`、应力 `1e-6 MPa`，见 [E-22](../explanations/E-22.md)、[`ADR-49`](../decisions/ADR-49.md)）。
  - 经正式入口对同一个含两个 `Step` 的文件跑"每帧 1 步 → 2 步"，记录父末、子首和结束时刻；追加后重读父样本摘要，应不变。
  - 补齐后在同一最终状态重跑 `C01`、`C04`、`C05`，都过则普通 `asrp run` 一次切到"新建会话 → 提交一段 → 导出"，并移除 `--candidate-build`（`asrp run --feb` 全程直调执行器）。

## 验收条件

> 只看到 `passed` 或退出码 0 不算交付，必须贴出真实命令与完整打印输出作为证据。

- **正向验收**：
  - 运行 `uv run pytest -s -k C05`，经 `asrp session create` 与 `asrp session advance` 完成新建会话、初始化和追加第二段。
  - 打印父末帧、子首末帧、绝对物理时间表、接头处控制值，以及与同实际样本整算的逐帧最大差（位置、速度、应力对照 `1e-5 mm` / `1e-4 mm/s` / `1e-6 MPa`）。
  - "先静后动"（首段不动、次段动下颌，验证通道预分配）和"非零后省略"（省略已转下颌通道时保持父末位姿）均通过。
- **必须失败的坏例**：
  1. 子段接头控制值与父末不符（接头跳值），必须报错并指出具体通道；
  2. 首段静止的可动下颌被写成永久固定导致次段无法驱动，必须失败；
  3. 追加子段时重复计算沉降或把省略通道拉回零位，必须失败；
  4. 子段里出现未知的非零通道，或无授权的数值覆盖，必须报错。
- **门禁验证**：交付最终状态跑 `uv run python tools/verify.py` 并记录实际输出。

## 历史与备注

- **为什么做**：
  - 实验室的钢琴界面每按一次键从上一段末状态续算，非中性初始化也是在同一场景前 14 帧把控制量移到起点姿态。
  - 旧运动转换器会自动补 0–14 帧沉降和末尾保持，且旧插值在追加新关键帧后会改写历史区间中点（复算输入 `[0, 1]` 与 `[0, 1, 0]` 时首个区间中点由 `0.5` 变为 `0.625`）。
  - 没有独立的 `motion` 和 `sessions` 层，就无法在不改写过去、不重复沉降、不误把下颌拉回零位的前提下实现连续多段仿真。
- **现在不定项与容差红线**：
  - 接头处是否提供端点速度**现在不定**（等实验室真实两次连续按键记录证明速度突变对研究任务造成可重复、显著影响后再增可选端点速度）；本卡首版不加端点速度，新段默认分段线性。
  - 续算一致容差（`1e-5 mm` 等）与旧场景迁移容差（`1e-9 mm`）分开登记，绝不用较宽的续算容差代替旧场景迁移验收。
