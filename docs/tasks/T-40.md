# T-40：给实验室机器的安装包

| 项目 | 内容 |
|---|---|
| **状态** | 🔴（原型机交付之后） |
| **前置依赖** | 原型机交付 |
| **产出** | 面向研究员的免命令行安装包与一页安装说明；改动 `blender_addon/`、打包脚本、`README.md` |
| **规模** | 中 |
| **关联文档** | [02](../02-requirements.md)（第 1 节、R-06 (b)）、[README](../../README.md)、[T-14](T-14.md) |

## 目标与范围

- **目标**：实验室的人拿到一个文件，双击或者在 Blender 里点几下就装好，不需要命令行、不需要自己装 uv 和 Python 环境。
- **为什么**：现在装插件前要敲一条命令打包，核心程序要用 `uv sync` 建环境，FEBio 要另外装（[README](../../README.md)）。研究员不用命令行（[02](../02-requirements.md) 第 1 节）。

## 关键规格与约束

- 先定打包的形式（插件包里带上核心程序和它的依赖，还是一个独立的安装程序）；
- FEBio 的许可不允许我们分发它的安装包（`.gitignore` 里的说明），所以安装过程要引导使用者自己装 FEBio 并检查装对了（`asrp doctor`）。

## 验收条件

- 在一台没有装过本项目的 Windows 电脑上，照一页说明装好并跑通原型机的三段运动，全程不开命令行；
- 这同时是 [02](../02-requirements.md) R-06 (b) 跨环境复现的第一次实测（[T-14](T-14.md)）。
