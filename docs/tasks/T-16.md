## 结论与现状

- **已完成**：
  - GitHub 私有仓库 `JoKFA/FEBio_Blender_Init`（[ADR-14](../decisions/ADR-14.md)），现有提交已推送；
  - 默认合并请求模板 `.github/pull_request_template.md`，内容和 [templates/pull-request.md](../templates/pull-request.md) 相同。
- **还要做**：
  - 开启 `main` 分支保护：必须经过合并请求、至少一人批准。
    - 注意：按 GitHub 官方的套餐说明，个人账号的**私有**仓库在免费版下不能开分支保护，要升级到 Pro，或者把仓库转到组织账号的付费方案。
    - 不升级的话，就靠规矩（[08](../08-engineering-standards.md) 第 3 节）加审查者把关；
  - 邀请成员，只邀请项目成员。

## 目标与范围

- **目标**：让多人能按 [08](../08-engineering-standards.md) 的流程协作。

## 验收条件

- 新开的合并请求自动带上模板；
- 如果开了分支保护，直接往 `main` 推送会被拒绝。
