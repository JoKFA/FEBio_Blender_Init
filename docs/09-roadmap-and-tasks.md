# 09 路线图与任务

这份文档把第一阶段拆成几个里程碑，每个里程碑再拆成任务卡。**任务卡就是交给开发者（人或 AI 开发会话）的完整说明**：拿到一张卡，加上 [README](README.md) 里开发者要读的文档，就能开工。所有任务卡都按 [templates/task-card.md](templates/task-card.md) 的格式写。

## 1. 里程碑

```
M0 基础 ✅ ──► M1 原料就绪 ✅ ──► M2 物理段 ──► M3 landmark 段 ──► M4 对比与评审 ──► M5 界面与验收 ──► 【关：T-17、T-18 复核 FEBio】──► 第二阶段投入

                                      │ T-06b、T-12 待做
```

**原则：先让真实资产从头到尾跑通一次，再逐项细化。** M2 先做一个粗糙但完整的第一版（T-06a），缺的数据用标明来源的临时值，这样真正的问题（四面体质量、尺寸、稳定性）能尽早暴露。

**原型机**（项目负责人 2026-11-11 确认，11 的 P-05；**定义只写在这里**，其他文档链到这一节）：**真实嘴唇在 Blender 里被下颌带动、由 FEBio 算出、能回放**，**不含** Ziva 对比（M4）和验收流程（M5）。**已完成**：T-06a 于 2026-11-11 跑通、评审后合并（PR #7、#8），早于目标日期 2026-11-17（2026-11-10 会议上说的"下周二之前"，[14](14-ziva-demo-walkthrough.md) 第 3 节 17:32；此前期待的是 1–2 周）。会议上还说不需要和 Ziva 对得很齐（11 的 Q12）。怎么重新跑一遍、结果是什么样：[15](15-prototype.md)；数字和证据命令在 T-06a 卡的"结果"。

原型机这条路是 **T-03、T-07（第 1、2 步）、T-08 的外壳 → T-06a**，全部完成。接下来 M2 还剩 T-06b（网格加密对照）和 T-12（换真实数据，等 Ziva 设置）。

**原型机二**（项目负责人 2026-11-11 提出，ADR-39；**定义只写在这里**）：在原型机上加 landmark 层，做实验室真正在做的两个动作，**不用到 Ziva 机器上取任何数据**：

1. **中性到 AA**：下颌按目标姿态转 5.74°，物理算出嘴唇被带动的形状，landmark 层再把它带到实验室的 AA 目标形状（目标姿态在实验室源码里，[03](03-asset.md) 第 13.7 节）。landmark 的位移由我们自己从目标形状拟合，不是实验室控制器的输出（那份运动文件在 Ziva 机器上，D2）；
2. **甩头**：按实验室脚本的关键帧让头左右平移（03 第 13.8 节）。验收是"能执行，并报告嘴唇相对头的晃动幅度"。只有嘴唇时预期看不出晃动（估计 0.01–0.05 mm，ADR-39 的证据），所以不把"看得见抖动"当作目标；
3. **附带**：同一段动作来回 10 次，网格不坏、每次回到起点的偏差不变大（检查 (d) 和 `return_to_settled` 就是尺子）。用我们自己的运动这一条几乎必然通过，它回答不了实验室提到的那个现象（11 的 A-39、P-06）。

它证明 landmark 层接通了、能做出研究员认得的口型；"到达目标"是拟合保证的，不证明物理对，也不证明和 Ziva 一样。任务是 T-09 → T-27 → T-28 → T-29（第 2 节）。

### T-07 粘连做法试验（S3） 🟢（第 1、2、4 步 ✅ 2026-11-11；第 3 步待做）
- **目标**：验证 [05](05-ziva-to-febio.md) 第 3 节定下的两种做法（上唇 `hard`、下唇和嘴角 `spring`）写得对，并给出弹簧基础刚度的取法。第 2 步的比较如果推翻了 05 第 3 节的类型，停下来报告，不自己改。
- **已完成的步骤**（结果在 05 第 3 节"T-07 第 1、2 步的结果"和 ADR-36，复现 `uv run python spikes/s3_attachment.py [--extra]`，快速部分 `uv run python -m pytest tests/test_s3_attachment.py`）：
  - 第 1 步：挂在 4 根弹簧上的方块，伸长和理论值 ρ·V·k²·g ÷（4K）比，k = 1 误差 1×10⁻⁹%、k = 2 误差 0.0165%；
  - 第 2 步：软方块用 `hard` 和 `spring` 粘在转动的板上，K 从 10⁻³ 加到 10¹⁰ N/mm，14 档单调趋近 `hard`（差 ≈ 2×10⁻³ N ÷ K）；零长度的单根弹簧不收敛，所以每个节点三根带偏移的弹簧，δ ≥ 10 × 最大滑移；
  - 第 4 步：六个自由度全固定的刚体可当颅骨用（05 第 1 节）。
- **还要做：第 3 步**：试验粘连权重小于 1 的情况，并和假设 A-23（"刚度 × 权重"，只是假设，以 Ziva 文档或实验室说明为准）一起验证，或者标明待定；结论写进 05 第 3 节，给出弹簧基础刚度的具体取法（现在是临时值 100 × E × h，05 第 3 节"基础刚度的具体数值：待定"）。
- **按照**：05 第 3 节；FEBio 手册（安装目录 `doc/FEBio_User_Manual.pdf`）：
  - 硬绑定：第 3.11.16 节的 `rigid` 边界条件，把一组计算点并入刚体；或者像 S1 那样让组织和刚体共用计算点；
  - 弹簧：第 3.6.7 节的 `DiscreteSet` 加第 3.16 节的 `linear spring`（刚度参数是 `E`）。弹簧的另一端需要一个计算点，再用 `rigid` 条件把这个点并入骨头。**一个弹簧材料只能有一个刚度**，所以"刚度 × 权重"要把权重分成几档，每档一种材料。
- **输出**：试验代码（放 `spikes/`），结论写进 05 和 10。
- **验收**：第 3 步有试验结果和结论（或明确标明待定及原因）写进 05；A-23 在 11 里相应更新；给出弹簧基础刚度怎么取的规则。
- **不做**：用实验室资产做试验。
- **依赖**：无。
- **改动范围**：`spikes/`、`docs/05`、`docs/10`。
- **规模**：小。

### T-09 landmark 变形层 🟡（下一个做；权重已有，物理段结果已有；完整验收等 T-10）
- **目标**：用 landmark 的运动和蒙皮权重，把变形叠加到物理段结果上（[04](04-architecture.md) 第 2 节）。

### T-23 方块上的主动收缩试验 🟢

### T-27 中性到 AA：拟合 landmark 位移并运行 🔴（原型机二第 2 步；等 T-09）
- **目标**：做出实验室的 AA 口型：下颌转到目标角度，物理算嘴唇，landmark 层把嘴唇带到目标形状。运动文件由我们自己生成，标 `source_tag: ours`。
- **为什么**：这是实验室真正在做的动作（[11](11-risks-and-questions.md) 第 1 节建议的那一条）。实验室控制器算出的运动在 Ziva 机器上（D2），但目标形状在源码里，够我们自己求一组 landmark 位移。

  1. 新工具（放 `tools/`）：读目标文件（用 `ast.literal_eval`，不执行；文件不进仓库，路径作参数），换成毫米、Z 朝上；从下颌网格拟合出 `jaw01` 的转动；写出运动文件：第 0 到 14 帧不动（`settle_until_frame: 14`），之后 36 帧下颌匀滑转到目标角度（实验室一段过渡是 36 个检查点，03 第 7 节）；

### T-28 甩头：颅骨能动，求解器保留动态效果 🟢（原型机二第 3 步）
- **目标**：按实验室脚本的关键帧让头左右平移，物理层能算完并报告嘴唇相对头的晃动幅度。
- **为什么**：这是实验室的被动动态实验（`automation/passive_dynamics_test.py`，03 第 13.8 节）。它要用到两样现在没有的能力（E-08 第 10 条）：颅骨按运动走，求解器不把动态效果全部抹掉。
- **先做的小试验**：在原型机上直接量。预期是看不出晃动：甩头的最大加速度约 0.12 g（平移 ±4.8 mm，每个来回 10 帧），而 1 g 的重力只让嘴唇下垂 0.095 mm，所以相对晃动估计只有 0.01–0.05 mm。先用一次运行确认或推翻这个估计，再决定下面的参数做到多细。
- **做法**：
  1. 运动文件：头的驱动源（新名字），第 16 帧开始 3 个来回，每个 10 帧，幅度 ±5 个场景单位，之后留 40 帧；`jaw01` 走同样的平移；
  2. 场景：颅骨和上牙改成跟着头的驱动源走。嘴角的锚现在是"下颌运动的 α 倍"，头动起来以后要改成"相对颅骨的运动的 α 倍"：`blend` 加一个可选的 `relative_to`（T = T_base · exp(α · log(T_base⁻¹ · T_of))），不写时和现在一样；
  3. 求解器：数值阻尼（现在写死成最大）、每帧子步数做成场景参数；物理阻尼先查 FEBio 4.13 怎么给，在方块上对一个有理论解的衰减振动，再接进生成器；
  4. 运行报告加一项只报告的量：每帧自由顶点相对头的位移（减去沉降后的值）的最大值。
- **验收**：
  - 方块：无阻尼时自由振动的周期和理论值差 2% 以内；有阻尼时振幅的衰减率和理论值差 10% 以内；
  - 真实嘴唇：甩头整段算完，检查通过；报告晃动幅度随时间的曲线，并和上面的估计比；
  - 头不动时结果和现在的原型机一致（差 10⁻⁹ mm 以内）。
- **不做**：调到"看得见抖动"；脸颊和皮肤（第二阶段）。

- **改动范围**：`scene.py`、`trajectory.py`、`generate.py`、`simulate.py`、`asset/lab.py`、`tests/`、`spikes/`、`docs/04`、`docs/05`、`docs/10`。
- **规模**：中到大。
