## 3. 运动传递链与运动文件格式（`.pkl`）

```text
① jaw01 转动（经 skinCluster1 带下颌、skinCluster2 带下牙） ─▶ ② 骨头刚体运动 ─▶ ③ Ziva 物理求解（输入 ShapeOrig）
   ─▶ ③' zEmbedder1 → polyTriangulate1（每帧拓扑可变、顶点序不变）
   ─▶ ④ landmark 蒙皮叠加（嘴唇 300 个 oor_NN 挂 joint_oor 经 skinCluster7；两眼各 300、额肌 300；嘴唇共四个 skinCluster）
   ─▶ ⑤ 最终回放形状（训练读静止+④，不含③） ─▶ ⑥ wrap6/7 曲线 → skinCluster13 皮肤显示面
```

- **实测验证**：蒙皮前 + `权重 × landmark 平移` 还原蒙皮后，47 帧 10,240 顶点最大误差 **`0.000016 mm`**（[E-11](explanations/E-11.md)）。
- **`.mb` 动画曲线**：12,134 条曲线均不随时间变化（12,120 条仅第 0/14 帧关键帧），故 `.mb` 不含运动。
- **运动文件 `combined_checkpoints.pkl`**（在仓库外，由训练日志 `final_epoch_action_list*.pkl` 累加并均匀取检查点，另伴 `overlap_metadata.pkl`；过渡表 167 条 → 161 目录 → 97 有文件 → **84 个文件 / 82 份不同**，全可读通）：
  - 每步 1 个 **`3,603`** 维向量：嘴唇 300 landmark 平移（900）+ `jaw01` 欧拉角（3，度；钢琴只用俯仰）+ 左眼 900 + 右眼 900 + 额肌 900。
  - 值为相对**本段参考**的累计偏移（不含起点姿态；仅从中性出发时参考 = 静止）；第 `i` 项对应 `start_frame_offset + 1 + i` 帧（首段从第 15 帧起）。
  - 步长有 3/10/22/25/36/43/46 步；中性到 AA 为 22 步、下颌 `−5.16°`、landmark 最大移 `12.1 mm`（已转存 `data/lab_export/trajectories/neutral_to_AA.json`）；46 份动下颌（最大 `0.37°–6.65°`），12 份只动眼或额头。

## 4. 单位、坐标轴与三种长度尺度

**固定导入顺序**（[ADR-16](decisions/ADR-16.md)、[ADR-18](decisions/ADR-18.md)）：
1. **套用物体世界变换**（已由 `tools/maya_export.py` 完成，导出的 OBJ 即为场景坐标，导入时核对 `obj_coordinates == "scene"` 绝不再套 `world_matrix`；各物体缩放不同：解剖 `2.54`、皮肤约 `1.185`、手约 `6.28`）。
2. **几何单位换算**：`units.mm_per_scene_unit = 0.962`（1 场景单位 = `0.962 mm`，与论文下颌 `155.92 → 150.0 mm` 及控制器 `9.62×10⁻⁴ m/单位` 一致；按此换算颅骨宽约 `217 mm`、前后约 `299 mm`，约为真人 `140–150 mm` 的 1.5 倍）。
3. **转坐标轴**：Maya（Y 上、脸朝 −Z）→ Blender/核心（Z 上、脸朝 +Y）：`(x, y, z) → (x, -z, y)`（纯旋转非镜像）。`jaw01` 场景坐标 `(0, -56.81, 126.52)` 换算为枢轴 `(0.00, -121.71, -54.65) mm`、转轴 `(1, 0, 0)`。

**三种互不相同的尺度**：① 几何换算 `0.962 mm/单位`；② 我方物理长度尺度 `k = 0.67`（真人大小，[ADR-31](decisions/ADR-31.md)）；③ Ziva 求解器缩放三轴 `100`（🔍 推断 100 单位 ≈ 1 m，待 [D18](11-risks-and-questions.md) 校准）。

## 5. Ziva 实测参数（2026-11-12）与保密边界

- **Ziva 实测汇总**：43 材料（`43 = 41 + 2`）全为 `12 kPa / 0.4 / 1060 / 体积保持 0`；140 粘连全软、`1×10⁸ N/m³`（`0.1 N/mm³`）、阻尼 `0.01`；求解器 `1` 子步/帧（源码注释写全质量 `2`、实测 `1`；整脸 AA 子步 2 对 1 差 `0.165 / 0.075 mm`）、牛顿最多 `5` 次、`30 帧/秒`、积分器 `BackwardEuler`、线性求解 `Direct`、刚度阻尼 `0.001`、质量阻尼 `0`、重力 `−9.8`（单位未核实 🔍）、碰撞检测关且所有软组织碰撞开关为 `0`（简写属性 `inT=3`、`newt=1`、`unL=319` 以实测为准）。
- **资产使用规则**：原始 `.mb` 只存 `assets/` 绝不提交；`data/lab_export/`、`data/preview/`、`data/tetmesh/` 仅进私有仓库不外传（[ADR-19](decisions/ADR-19.md)）；审稿论文与渲染网格不对外公开。
