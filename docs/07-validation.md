# 07 验证与验收

给谁看：开发者、审查者与实验室负责人。
读完能知道：地基阶段如何按“实验 × 场景家族”分项签收、各类裁判各管什么、持续生效的自动检查与合理性检查是什么、如何与 Ziva 对比，以及发现明显偏差时按什么顺序排查。

> **核心原则（[ADR-17](decisions/ADR-17.md)）**：目标是让实验室能用新的物理层继续研究，不是逐点复刻 Ziva。
> 合格线不是“和 Ziva 差几毫米以内”，而是工程检查过关、跑过廉价对照、研究员评审可接受；对 Ziva 的毫米差照实报告。
> 原型期旧验收流程与对外口径已归档至 [archive/prototype/07-v1-validation-history.md](archive/prototype/07-v1-validation-history.md)。

## 1. 地基阶段验收：研究员四项签收、裁判分工与手算裁判

地基阶段验收按**“实验 × 场景家族”**拆分，不把单块嘴唇的通过外推为整个系统的通过；每项独立记录三个状态：**有无同条件参考 / 工程是否通过 / 研究员是否认可**（无同条件参考标“未核实”，不拿别处实验顶替）。

### 1.1 研究员的四项签收（待实验室确认结论与等待门限，[11](11-risks-and-questions.md) D22）

| 签收项 | 场景家族 | 起步方式 | 看的对象与层 | 现有参考概况 |
|---|---|---|---|---|
| **训练查询** | 不带皮肤族（[03](03-asset.md) §1） | 默认静止形状不走时间；非中性另记初始化 | 四组 landmark 网格（嘴唇、两眼、额肌）+ 下颌（原序世界坐标） | 仅嘴唇有 145 份存档；下颌与其余三组缺逐点对照 |
| **连续表情** | 待定（源码注释写无皮肤，演示用带皮肤） | 纯重力沉降或非中性起步；续算显式指定父状态 | 各对象按 `(对象, 表面, 层)` 读取（仅 `physics` / `final`；刚体出 `physics`，眼额 `final` 待验证） | 仅有单段 AA 与若干音素；缺连续两次真实按键记录 |
| **带皮肤被动动力学（甩头、按压）** | 带皮肤族（🔍 推断） | 先沉降再动；按压另记实验室皮肤几何修正 | 皮肤布料 `physics`（取到曲线绑定数据并验证后才发 `final`）+ 嘴唇 | 甩头有整张脸参考（我方待 [T-33](tasks/T-33.md) 收敛）；缺皮肤逐帧参考 |
| **回中性** | 按现场实际家族填 | 清控制输入回第 0 帧重新初始化，与冷启动核对 | 同“连续表情” | 须与同输入同设置冷启动比第 0–14 帧及后续同一动作 |

### 1.2 六类裁判的分工与边界

| 裁判 | 证明什么 | 不证明什么 |
|---|---|---|
| **手算 / 理论值** | 力学公式、单位、面积加权、重叠粘连、参考点规律没写错 | 真实模型规模；Ziva 实际行为 |
| **FEBio 官方算例** | 经 `asrp` 正式生成器重写并对上官方值才覆盖生成器（由首个实现能力的卡验：`T-46`、`T-49`、`T-51`） | 我们自己的网格与粘连；原样跑通只证安装 |
| **整算对续算 / 分支 / 删档重放** | 续算没改写过去、没丢历史、坏档会被拦截 | 物理模型对不对 |
| **结果清单读回对照** | 数组确实属于该对象、表面 ID、层、帧与原序顶点（坏例：同点数换场景、换两行顶点、层对调、错帧；合法重三角化须通过） | 数值物理是否合理 |
| **Ziva 同条件参考** | 和旧物理层差在哪（不设通过线，无参考时健康段仍可提交并标“未核实”） | 跨范围对照（整张脸 vs 局部切片差可达 7.98 mm） |
| **研究员评审** | 动作能否用于继续研究 | 工程实现正确性 |

> **关键分工**：组织接对了（`T-50` 嘴周 11 组织切片）与皮肤力传对了（`T-51` 渐变重叠皮肤小片）分开裁定。

|---|---|---|---|

求解器本身引用 FEBio 已发表验证（Maas 等，2012）；以下管线检查每次提交都跑，**每踩一个新坑，就加一个能因它失败的测试**（断言具体误差或数量，而非仅“非空”）。

| 检查 | 证明什么 | 测试位置 |
|---|---|---|
| 刚体绕铰链转动与重力往下沉 | 驱动与重力符号正确（[05 坑 1](05-febio-pits.md)） | `tests/s1_dynamic_jaw.py`（`test_febio.py`） |
| 简单方块拉伸与悬挂理论解 | 材料与单位换算正确（悬挂差 `0.22%`/`0.43%`，横向收缩差 `0.001`） | `tests/test_generate.py` |
| 导出与导入精度 | `.mb` 对 OBJ `≤ 0.001` 场景单位；换算系数与轴导入误差 `< 0.001 mm`；下颌前后 `150.0 mm` | `tools/check_lab_export.py` · `tests/test_asset.py` |
| 场景校验、点缓存与静止嵌入 | 错字段/缺文件/坏哈希运行前停下；点缓存格式正确；静止嘴唇嵌入差 `7×10⁻¹⁴ mm` | `tests/test_scene.py` · `tests/test_playback.py` · `tests/test_generate.py` |
| landmark 静止恒等与回放一致 | landmark 不动时最终=物理；Blender 回放误差 `< 0.001 mm` | `tests/test_simulate.py::test_landmarks_at_rest_give_a_final_that_is_the_physics_exactly` · `tools/check_playback.py` |

## 3. 真实资产合理性检查（`asrp run` 自动执行）

由 `src/asrp_core/plausibility.py`（地基迁入 `checks`）写入 `run_report.json`；任一 `false` 面板标红且 `asrp run` 以 `1` 退出；`passed` 为 `null`（没运行，汇总于 `not_run`，[ADR-37](archive/decisions/ADR-37.md)）不算失败，但 (a) 必须为 `true`。

| 检查 | 通过标准 | 抓什么错 |
|---|---|---|
| **(a) 整段算完** | 没有最终失败的帧（中途报负体积自动缩步重算成功不算失败，报告重试次数） | 网格质量、步长或刚度失稳 |
| **(b) `hard` 粘连跟骨头** | 每帧计算点与嵌入 `hard` 显示点相对骨头 `< 0.001 mm`；`spring` 只报告偏离 | 变换约定与粘连回归检查（非物理精度证明） |
| **(b2) 弹簧锚跟刚体** | 每帧弹簧锚点相对刚体 `< 0.001 mm`（几何毫米） | 下颌/嘴角锚驱动错误（回归检查） |
| **(c) 重力沉降量级** | 第 `0..n` 帧驱动源静止（`simulate._still_until`，误差 `1e-9`）时记 `settled_shape.frame = n`，取沉降最后 5 帧（`max(1, n-4)..n`）自由顶点下移均值在 `ρ·|g|·k·L²/(2E)` 的 `÷10` 到 `×10` 内（`L` 为自由点到最近权重大于 0 粘连点的最大直线距离） | 重力反号必败（`test_check_c_fails_when_the_gravity_flip_is_lost`）；单位/`k`/刚度错十倍以上 |
| **(d) 四面体有效** | 整段每帧每四面体 `有向体积 / 静止体积 > 0` | 单元压翻或拉坏 |
| **显示面健康（只报告）** | 报告末帧与最差帧的翻转面数和短边数，与 Ziva 并排（[ADR-43](decisions/ADR-43.md)） | 显示表面质量异常 |
| **`return_to_settled`（只报告）** | 驱动回到静止（`10⁻⁹` 内）的帧相对第 `n` 帧最大/平均距离（原型第 50 帧约 `0.004 mm`） | 回中性漂移 |
| **末 10 帧晃动（未实现）** | 原设计要求只报告末 10 帧晃动幅度；**当前代码未实现**（相近只报告项为 `return_to_settled` 与 `relative_to_head`） | 阻尼衰减（待负责人确认补写或删要求） |

> **(c) 校准记录**（2026-11-11，真实嘴唇 `k=0.67`）：`L = 25.05 mm`，估计 `0.146 mm`，实测 `0.0952 mm`（比值 `0.65`，符合悬臂杆约 `2/3`）；`E × 10` 实测 `0.0106 mm`、`E ÷ 10` 实测 `0.93 mm`，与 `1/E` 一致。

### 4.2 对比口径与 `asrp compare`

- **输入要求**：两边须为同网格 `10240` 顶点、同帧数、`30 帧/秒`（不符即报错，不截断不重采样）；按流校验 `seal.json` 哈希与长度；Ziva 点流从 `<流>.points.f32` 读，乘 `mm_per_scene_unit` 并转轴 `(x, -z, y)`。
- **逐帧毫米差**：全部 `10,240` 嘴唇顶点，物理段与最终形状分开报平均差别、95% 顶点差别（P95）与最大差别；两列并报 Ziva 整张脸（参照）与只留嘴唇（敏感性实验，不作验收依据；两者自身第 36 帧差平均 `1.98`、最大 `7.98 mm`）。
- **两项不依赖 Ziva 的参考指标（[ADR-25](decisions/ADR-25.md)）**：
  1. **到美术目标姿态距离**（`--target` 读 `dataV22_*` 的 `x_middleres_OrbicularisOris1` 与起始组 `...0`；缺输入写 `available: false`）：报训练态（`final_shape.rest_model` 残差）、我方最终形状、Ziva 最终形状及 `最终 ÷ 初始`（论文 11% 只作参考非合格线；回放含下颌带唇，Ziva 自身离目标平均 `11.64 mm`）。
  2. **下唇跟随比例（纯物理段）**：`Σ(u·r) ÷ Σ(r·r)`（下唇 76 顶点 `lower_lip_on_jaw`，按第 0 与第 14 帧各报；Ziva AA 下唇平均动 `11.80 mm`）。
- **`asrp compare` 输出**：`compare_report.json`（格式 `asrp-compare/1`，无本机路径）、热力图 `heatmap.json`（`asrp-heatmap/1`：含 `units`/`frames`/`vertex_count`/`fps`/`dtype`/`layout`/`reference` 与每层最大/平均/P99）+ 裸 float32 `.f32`（小端，帧在前、顶点在后，下标 `f × vertex_count + v`，单位毫米；插件用 `array.array` 直读免 numpy）、Ziva 回放包 `ziva_playback/`（用第 0 帧 `lips_physics.obj` 拓扑并写明，回读差 `≤ 1e-4 mm`）；拒绝写进未 git 忽略路径。

### 4.3 廉价对照：下颌直线预测（硬性对比规矩，2026-11-21 定）

> **以后每一次物理验收对比，都在同批运动上同时给 FEBio 和下颌直线对照打分并一起报告；哪条运动上 FEBio 跑不过这条直线对照，那条运动就不算物理层的证据。**

只取 Ziva 整张脸 AA 第 14 帧和第 36 帧，给每个嘴唇顶点拟合一条随下颌角变化的直线（不在测试音素拟合），代入测试音素的真实下颌角预测物理层（各以第 14 帧归零算第 15 帧至末帧时空 RMS，mm；数据见 [E-23](archive/explanations/E-23.md)）：

| 测试运动 | 嘴唇静止不动 vs Ziva (mm) | 下颌直线对照 vs Ziva (mm) | 说明 |
|---|---:|---:|---|
| EH / V / N | `2.704` / `1.650` / `2.649` | **`0.104` / `0.252` / `0.104`** | 普通张嘴音素仅靠下颌直线就能预测到 `0.1–0.25 mm` |
| IY / UW / T | `0.009` / `0.009` / `0.010` | `0.009` / `0.009` / `0.010` | 物理层本身几乎不动（UW 物理 RMS `0.008 mm`，landmark `4.036 mm`；AA 物理 `6.710 mm`，landmark `1.745 mm`） |

**边界与含义**：此对照只限同资产从中性出发，不覆盖续算、换脸、改材料、碰撞或甩头。物理层的真正证据来自受控扰动（变速、停住、改约束、甩头与邻近组织传力）。

### 4.4 研究员评审 6 问（写进 `review.md`）

研究员在 Blender 并排播放与看热力图，对每问选“可以接受 / 需要改 / 不能接受”并写理由。**通过标准**：没有“不能接受”，“需要改”已修或写明暂受理由；第 6 问若答“会改变判断”则不通过，须先查明离散原因：
1. 下颌张合时嘴唇跟得自然吗？
2. 有无不该有的抖动、鼓包、塌陷或撕裂？
3. 重力下垂程度可信吗？
4. 叠加 landmark 后表情还认得出来吗（如 AA）？
5. 与 Ziva 差别大的区域能接受吗？
6. 看网格敏感性报告（3 份独立网格 + 8 分保持几何细分 + 子步加倍，[ADR-23](decisions/ADR-23.md)）：离散差别会不会改变你的研究判断？

## 5. 差别明显时的 7 步排查顺序

仅当影响评审或合理性检查失败时按序排除（时间上限见 [T-12](tasks/T-12.md)）：
1. **单位与坐标轴**：先比第 0 帧静止形状，不对即查导入。
2. **重力沉降**：逐帧比第 0–14 帧（Ziva 整张脸均 `0.29`/最大 `1.2 mm`；只留嘴唇均 `1.8`/最大 `5.4 mm` 且未停稳，待 [D17](11-risks-and-questions.md)），排查密度、刚度、重力与尺度 `k`。
3. **下颌刚体驱动**：比下颌位置，刚体必须完全一致。
4. **粘连固定方式**：比挂骨顶点，排查粘连对应与刚度（[05](05-ziva-to-febio.md) §3）。
5. **阻尼与子步**：确认我方阻尼/子步，再比振荡幅度与衰减（Ziva 整脸 AA 子步 2 对 1 差 `0.165`/`0.075 mm`）。
6. **网格与时间步**：查保持几何 8 分细分与子步加倍是否收敛（换包络改嘴角小孔，不算纯分辨率对比）。
7. **landmark 蒙皮层**：物理差小而最终差大，查蒙皮层。
