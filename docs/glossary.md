# 术语表

给谁看：读其他文档时遇到不熟的词的人。解释以“在本项目里指什么”为准；已退场概念只留一行说明现用什么。

## 核心结构与会话（地基 v2 核心术语，[architecture/](architecture/README.md)）

| 词 | 在本项目里的意思（及禁混用项） |
|---|---|
| **静态导出包** | 一次从源环境采得的只读数据集合，记采到什么与缺什么（[scene-and-data](architecture/scene-and-data.md)）。不混用：可执行场景、导入器 |
| **场景版本** | 按规范化清单 SHA-256 定位的一组对象、关系、物理与显示声明（[ADR-46](decisions/ADR-46.md)）。不混用：资产版本、`.blend`、格式版本 |
| **场景视图** | 核心发布给宿主查看、选择与高亮的只读运行前清单（[ADR-46](decisions/ADR-46.md)）。不混用：原始导出包、结果清单 |
| **建造配置** | 决定如何把场景变成计算模型的独立版本化 JSON 选择（[ADR-47](decisions/ADR-47.md)）。不混用：场景材料、段求解设置 |
| **建造记录** | 会话锁定的不可变计算模型及其网格、对应、有效选择和编号表（[ADR-47](decisions/ADR-47.md)）。不混用：导入报告、单次 `.feb` |
| **段** | 从指定父状态出发的一段控制输入、时间范围与已解析驱动样本（[ADR-49](decisions/ADR-49.md)、[ADR-54](decisions/ADR-54.md)）。不混用：单帧、一次尝试 |
| **状态** | 一次成功提交的历史终点，含完整物理历史与重放记录（[ADR-49](decisions/ADR-49.md)）。不混用：表面快照、`.dmp` 存档 |
| **尝试 / 缓存** | 尝试是一次执行的独立工作目录；缓存（`.dmp`）是可删并由保留记录重放重建的加速文件（[ADR-49](decisions/ADR-49.md)） |
| **结果层** | 公开层名固定只有 `physics` 和 `final`，按 `(状态, 对象, 表面 ID, 层, 帧)` 输出原序世界坐标（[ADR-52](decisions/ADR-52.md)） |
| **训练查询** | `asrp_query` 在已载入静态模型上按位姿进程内读网格的无状态调用（[ADR-53](decisions/ADR-53.md)）。不混用：推进物理段 |
| **参考表面** | 固定原始点序、承载权重或读取身份的静止表面（[scene-and-data](architecture/scene-and-data.md)）。不混用：计算网格、逐帧三角面 |
| **粘连边** | 有独立 ID、从指定源表面到指定目标的物理声明（[ADR-51](decisions/ADR-51.md)）。不混用：一对物体、一根弹簧 |
| **逐点对应** | 一条边内源材料点、目标落点及两侧计算支撑的记录（[ADR-51](decisions/ADR-51.md)）。不混用：求解器行、最近物体 |
| **参考点规律** | 规定目标运动时间隙另一端受力参考位置如何变化（[ADR-51](decisions/ADR-51.md)）。不混用：目标落点、`maintainOffset` 开关 |
| **资产** | 专指实验室给的原始材料（`.mb`、导出包、运动文件）；核心管理的物理定义改称**场景版本** |
| **旧“第一/第二阶段”** | *已退场分法*：早期文档里指“单嘴唇原型 / 全脸扩展”。2026-11-24 收敛后按**“已交付原型基线 → 地基阶段（T-42–T-52）→ 地基之上按依赖展开”**表述（[09](09-roadmap-and-tasks.md)） |

## 软件、数据与格式

| 词 | 意思 |
|---|---|
| **Maya / Ziva** | 实验室现有商业 3D 软件与物理插件（Ziva 已于 2024 年停售），本项目替换其物理与宿主层 |
| **Blender / 插件** | 免费开源 3D 平台；本项目插件只管界面，不含求解逻辑与第三方库 |
| **FEBio / FEBio Studio** | 犹他大学开源生物力学有限元求解器（替代 Ziva）；ArtiSynth 为未来可选第二求解器 |
| **zBuilder / zGeo** | Ziva 整套导出工具 / Ziva 为每物体保留的网格副本（原 Maya 网格删后仍在） |
| **权重表（weightList）** | 逐顶点 `0–1` 数组；Maya 仅存偏离默认值元素，粘连权重的默认值是 `1.0`（演示场景上唇有直接证据，第二家族待证） |
| **`.mb` / 非 Ziva 版 / mayapy** | Maya 二进制场景 / 删去 Ziva 节点的 `w64` 副本 / Maya 命令行 Python |
| **Ziva 机器** | 实验室装有 Ziva 许可的共享电脑（2026-11-12 首趟取数，可再去） |
| **`.feb` / `.rst` / `.dmp`** | FEBio 首次输入文件 / 重启续算输入 / 可清理二进制求解存档 |
| **回放包 / PC2** | `playback.json` + `playback.pc2` 点缓存，用于 Blender 逐帧回放（地基下为派生文件） |
| **`combined_checkpoints.pkl`** | 实验室运动文件：每步 `3,603` 维向量（嘴唇/两眼/额肌各 900 + 下颌 3 欧拉角），相对本段参考累计偏移，仓库外存 84 份；不同于我方 `trajectory.json` |
| **`dataV22_*`** | 实验室目标姿态文件：`…0` 为静止形状（无沉降），`…1` 为控制器目标形状 |
| **`.gitattributes` / `autocrlf`** | 强制 `data/` 与 `tests/fixtures/` 按字节检出（`-text`），防 Windows 换行转换破坏 SHA-256 哈希 |
| **uv / git / PR** | Python 包管理器 / 版本管理 / 合并请求 |

## 几何、物理与面部控制

| 词 | 意思 |
|---|---|
| **四面体网格 / `tetSz`** | 把实体切分为四面体做有限元计算；`tetSz` 决定网格粗细 |
| **嵌入（`zEmbedder`）/ 重心坐标** | 精细显示网格绑定在粗四面体上，按四面体四角重心坐标插值随动（原型粘连亦复用嵌入四面体） |
| **8 分细分 / 网格敏感性报告** | 每四面体按边中点切 8 份做保持几何加密；与独立网格、时间步加倍合成报告（只报不设通过线，交研究员评判，[ADR-23](decisions/ADR-23.md)） |
| **节点 vs 计算点** | Maya 里的“节点”指场景对象；有限元里的“计算点”指四面体网格顶点 |
| **物体坐标 vs 场景坐标** | 网格自带坐标 vs 套用缩放/旋转/平移后的世界坐标（Ziva 用场景坐标；实验室网格缩放不统一） |
| **静止形状（`ShapeOrig`）** | 变形前原始网格，作为 Ziva、蒙皮与训练查询默认基底 |
| **软组织 / 刚体 / 粘连** | 可变形体积（`zTissue`）/ 仅整体运动不变形物体（`zBone`）/ 物体间带权连接（`zAttachment`） |
| **`zMaterial` / 本构 / 模量 / 泊松比** | Ziva 场景 43 材料全为 `12 kPa / 0.4 / 1060`，本构 `StVK`（抗压 `20000`）；我方用 `neo-Hookean` |
| **壳单元（ANS / EAS）** | 算皮肤等薄层的单元；FEBio 4.13 必须用 `ANS`，`EAS` 重启会崩（[05 坑 21](05-febio-pits.md)） |
| **数值阻尼（`rhoi`）/ 质量阻尼** | 广义 α 算法自带高频阻尼（默认 `0` 最强）/ FEBio `mass damping` 体载荷 `f = −Cρv`（默认 `0`） |
| **动力学 vs 准静态 / 子步** | 考虑惯性与晃动 vs 忽略惯性；一帧可拆多个子步求解 |
| **OOR / ooc / landmark / 蒙皮** | 口轮匝肌（嘴唇）/ 眼轮匝肌 / 驱动表情的关节控制点（每组 300 个，共 4 组）/ `skinCluster` 线性混合蒙皮 |
| **控制器 / 音素 / 蒙皮前与后** | 实验室优化出下颌与 landmark 驱动的算法 / 发音单位（如 AA）/ 物理层输出 vs 叠加 landmark 后最终形状 |
| **mm、N、MPa、s / 物理尺度 `k`** | 项目统一单位（质量单位吨 `t`，只在导入时换算一次）；`k = 0.67` 将 1.5 倍模型按真人大小送入 FEBio（进乘出除） |
| **派生驱动源 / 嘴角锚（`α = 0.5`）** | 原型嘴角近似刚体，取下颌刚体运动比例 `α = 0.5` 随动（地基多组织切片由真实嘴周组织取代） |
| **验证门 / 合理性检查** | `tools/verify.py` 合并门禁（`docs`/`core`/`full`）/ `asrp run` 自动跑的 (a)(b)(b2)(c)(d) 物理健康检查 |
| **哈希值（指纹）** | 文件内容 SHA-256 摘要，改一字节即变，用于防漂移与溯源 |
