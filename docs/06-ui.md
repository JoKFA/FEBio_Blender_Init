## 1. 地基阶段宿主约定（已定，[architecture/](architecture/README.md)）

插件代码位于 `blender_addon/asrp_blender/`，严禁含求解计算逻辑或第三方依赖，所有动作走 `asrp` CLI。地基重构（[T-44](tasks/T-44.md)、[T-50](tasks/T-50.md)）后宿主遵守五条约定：

1. **`.blend` 只存引用，不是数据真身**：`.blend` 保存 `store_id`、场景版本 `revision`、相对路径提示及当前会话/状态 ID；“另存为”继续引用同一不可变版本，编辑参数经核心生成新版本，只更新发起编辑的文件（[ADR-46](decisions/ADR-46.md)）。
2. **只读场景视图与结果清单**：插件不再直接解析 `scene.json` 或按组织名硬找 `lips_object()`；运行前读核心发布的只读**场景视图**做列表与高亮，回放读公开**结果清单**（`results.json`，按对象、表面 ID、层 `physics`/`final` 加载，[ADR-52](decisions/ADR-52.md)）。
3. **回放身份严格校验**：导入时在网格写入场景版本、表面 ID 与逐顶点原始行号；接点缓存前核对原始行号、参考表面静止坐标与连接关系（替代原型仅查顶点数相等的脆弱检查）。
4. **模块化与后台作业隔离**：`__init__.py` 只留注册，拆出场景/高亮、后台作业、回放模块；后台子进程管理器由 `RunSession` 改称 **`RunJob`**（避免与物理会话混名），启动即绑定发起文件、场景版本与父状态，中途切 `.blend` 仍可回原文件取回结果。
5. **承接新模型创建**：Ziva 停售后，支持研究员直接在 Blender 里标角色（骨头/组织/皮肤）、编辑粘连并发布新场景版本（[T-39](tasks/T-39.md)，前置仅需 `T-44` + `T-46`）。

## 3. 已交付原型机（v1）面板现状摘要

当前可用版本位于 Blender 3D 视图右侧边栏（N 键）**ASRP** 标签，**面板文字一律英文**，已由 [T-35](archive/tasks/T-35.md) 跑通并通过 `tools/check_panel.py` 无窗口检查。

### 3.1 设计原则与布局硬约束

- **五原则**：按研究员顺序自上而下排列；每步有明确状态（前置未完成则置灰并提示原因）；错误信息说人话；每个参数显式标明来源（`measured in Ziva` / `our own values`）；后台求解不卡界面。
- **尺寸红线（`tools/check_panel.py` 强制核对）**：默认侧边栏宽 `280 px`，单行上限 **`34` 字符**（带图标 `32` 字符，超长折行；运动标题也限 `34` 字符）；默认展开状态下从顶部到 Results 按钮总高 **`≤ 650 px`**（1080p 免滚动，全展开必须超过 650 px 以证检查可失败）。
- **找项目顺序**：`ASRP_PROJECT` 环境变量 → 插件偏好（`Choose project folder` 校验含 `pyproject.toml` 和 `src/asrp_core` 并存盘）→ 插件所在仓库目录。

### 3.2 八个小节与三步流程

| 顺序 | 面板小节 | 默认状态 | 核心功能 |
|---|---|---|---|
| 1 | **1  Open the asset** | 展开 | 单选网格：**Coarse lattice**（默认，126 tets，~1 s，配 `--attachments ziva-soft`）或 **Fine**（26,721 tets，~30 s，配 `--attachments ours`）；一键创建 5 个真实尺寸网格物体 + 黄色 `ASRP landmarks`（300 个八面体，播放时自动隐藏），隐藏罩住资产的默认 Cube 并将视图正面居中（2.6 倍半径）；折叠含 `Asset details` |
| 2 | **Physics setup** | 收起 | 只读列出角色、材料与来源、四组粘连（点击视口高亮） |
| 3 | **2  Choose a motion** | 展开 | 从 `trajectories/` 列运动（原型一张嘴 12°、原型二中性到 AA 与甩头共用同一资产），不手输路径 |
| 4 | **3  Run** | 展开 | 后台运行整段并显示进度/取消；防双击（运行中及刚结束 1 秒内拒再按）；算完结果原位更新到 5 个物体并直接在 Blender 时间轴播放，固定提示“Computes the whole motion, then replays it. Not frame-by-frame.”；锁定视角不漂移 |
| 5 | **Results** | 展开 | 切换 `Physics only` 与 `Final shape`；支持 `.blend` 存盘重开，外部目录丢失给出明确提示 |
| 6 | **Compare with Ziva** | 收起 | 选 Ziva 导出目录运行 `asrp compare`，加载并排 Ziva 物体与顶点色毫米差热力图 |
| 7 | **Checks** | 收起 | 读 `run_report.json` 列出合理性五项 `PASS / FAIL / NOT RUN`（失败标红） |
| 8 | **Advanced** | 收起 | 切换项目目录、`Check backend`、`Load result`、`Load run folder`、折叠的 `Run other files`（手输路径） |

> 实验室在 Maya 中的“钢琴界面”归实验室所有，不属于我们的面板范围（操作记录见 [14](14-ziva-demo-walkthrough.md)）。
