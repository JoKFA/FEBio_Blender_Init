# E-24：地基为什么要分成场景、建造、段、结果四处？隔着几毫米到几厘米的粘连为什么要这样算？

- **日期**：2026-11-24 提问
- **依据与关联**：
  - [地基架构](../architecture/README.md) 四页（[architecture/README](../architecture/README.md)）、[术语表](../glossary.md)
  - [10](../10-decisions.md) [ADR-46](../decisions/ADR-46.md) 到 [ADR-54](../decisions/ADR-54.md)

- **权威声明**：本文只讲理由与边界；结构细节以 [地基架构](../architecture/README.md) 四页为准，正式决定以 [10](../10-decisions.md) 为准。

## 核心结论

- **为何拆成“场景、建造、段、结果”四处**：原型按“一块嘴唇、从静止整段算、算完直接回放”搭出，直接扩到多组织、皮肤和连续推进有五处瓶颈撑不住。切开四处后，不同原因引发的变动互不牵连：
  - 接着算时复用同一份建造和父状态；
  - 换计算网格或粘连算法只重做建造，原场景、旧结果和历史实验记录仍可用；
  - 换结果读取宿主只经结果层，不翻底层场景文件；
  - 实验室训练查询走独立打包静态模型，无需状态、帧或结果清单。
- **为何这样算长间距粘连**：演示场景 140 条粘连多隔着几毫米到几厘米，且 49 条皮肤粘连带逐点渐变权重。FEBio `tied-elastic` 单接触仅一罚系数、目标转动时把间距固定在世界系，且 `search_radius` 留 0 时漏配对仍静默正常结束。
- 下颌实测最大仅转 6.65°，单靠转动不足以排掉 `tied-elastic`，真正让逐点约束优先的是**保留渐变权重**与**把力和力矩传到正确位置**。
- **当前候选（[ADR-51](../decisions/ADR-51.md)）**：需要逐点软刚度和双向传力的可变形目标，先接入本机合成小算例验过 9 项的“目标四面体外推参考点 + 纯罚线性约束”（真实网格、壳源、刚体目标未试）。
  - 49 条渐变边中，30 条皮肤→组织仅获目标侧机制合成证据（真实壳源待 [T-51](../tasks/T-51.md)），19 条皮肤→骨仍待刚体偏心传力试验。
  - 逐点写出作基准，按单元对 QR 合并为可选写法（默认是否开启待真实模型计时）；Ziva 变形目标究竟按哪条规律走未量过，待上机定去留。

## 一、原型的结构在哪些地方撑不住

原型在单块嘴唇范围内能跑通，但承接实验室原本用法（41 块软组织、2 层皮肤、10 块骨头、140 条粘连、连续按键推进、Blender 与实验室训练两类调用）时，有五处撑不住：

| 瓶颈 | 简要表现 | 为什么挡住地基 |
|---|---|---|
| **1. 一块组织写死** | 生成器、运行、回放、插件四处均按“正好一块软组织”写死（[E-21](../archive/explanations/E-21.md)） | 扩不到多组织、两层皮肤和多骨头的真实场景 |
| **2. 按单段运动决定骨头固定或可动** | `generate.py` 第 326–343 行按本段有无驱动决定固定/可动；`Model` 绑死一切 | 对冷启动整段算成立，对先静后动的连续会话会把骨头建错成永久固定；FEBio 重启不许改结构 |
| **3. 插件直读场景，回放只查顶点数** | 插件靠组织名找物体，`show_layer()` 第 791 行仅核对顶点数相等 | 同点数换错资产或换两行坐标查不出；格式一升级插件即碎 |
| **4. 整段冷启动，插值与转换器不适合分段** | 无状态历史；旧 `smooth` 追加会改写过去；转换器只管嘴唇且自动补沉降 | 追加改过去、续算重沉降；只动眼/额的运动被静默算空 |
| **5. 原地改写存档，重试错得悄无声息** | FEBio 同名覆写存档；途中杀进程重试 12 次里 11 次走到第 70 帧却“正常结束” | 失败或取消污染历史且检查可能漏报 |

瓶颈依据细节：

- **第 2 项**：内部对象 `Model` 把单块组织、一段运动、FEBio 节点号和最终 XML 绑在一起；“FEBio 重启不允许增加刚体或改动模型结构”系读 FEBio 源码，未实跑。
- **第 3 项**：插件 `lips_object()` 按组织名找物体；回放入口 `asset.py` 的 `show_layer()`（第 791 行）只核对点缓存与物体顶点数。
- **第 4 项**：旧 `smooth` 插值（单调三次 Hermite）会因后续追加关键帧改写已算区间；旧转换器自动补第 0–14 帧沉降和末尾保持，且只处理嘴唇 900 个平移数与下颌，忽略眼周和额肌其余 2,700 个数（实验室 84 份运动中 **12 份**只动眼或额头，[E-23](../archive/explanations/E-23.md)）。
- **第 5 项**：FEBio 一次运行只写一个存档文件，同名覆写（读源码，未实跑）。
  - 本机 3 块组织合成模型上，新存档写回父档原路径、途中杀进程重试，**12 次里有 11 次“正常结束”且健康检查通过，实际走到第 70 帧（预期第 46 帧）**；续算不加写档选项时起点存档未被改动（[E-23](../archive/explanations/E-23.md)）。
  - 另发现试验脚本曾先筛掉期望帧以外记录再做健康检查，会提前丢掉越界证据。

| 边界 | 一句话职责 | 解决瓶颈 | 对应决策 |

| **建造**（`build`、`backends/febio`） | 说明**这次具体怎样模拟**：计算网格、粘连落点与传力、驱动通道 | 第 1、2 项 | [ADR-47](../decisions/ADR-47.md)、[ADR-48](../decisions/ADR-48.md) |

各边界关键约定与实测依据：

- **场景**：用稳定 ID 表达任意数量组织、骨头、皮肤和粘连边；对外发布只读**场景视图**，插件不再直接解析 `scene.json`。内容摘要定版，小清单配按摘要共享大文件；`.blend` 只存仓库标识和版本引用，首版不自动删已发布版本（[ADR-46](../decisions/ADR-46.md)）。
- **建造**：把“整次实验固定的计算模型”从“这次提交才知道的运动”切开；所有声明可驱动且纳入建造的骨头从首段起分配完整通道（首段未动给零运动）。建造配置独立，**建造记录**不可变落盘；细网格离线生成一次核对摘要，规则格子可建造时生成封存（[ADR-47](../decisions/ADR-47.md)）。
  - 旧场景同样预分配通道，不留兼容开关（[ADR-48](../decisions/ADR-48.md)）。
  - 本机原型中性到 AA（粗格子，224 节点，46 帧，1 线程）实测“固定”与“给定零位移”的日志坐标（已乘物理尺度 0.67）最大差 **1×10⁻¹⁰**（日志 12 位有效数字最后一位），折合几何约 1.5×10⁻¹⁰ mm，低于 `1e-9 mm` 回归门限。
  - 以上只试了这一个模型、这一段运动（[E-23](../archive/explanations/E-23.md)），切换前再补受力方式与先静后动用例。
- **段**：状态（输入、实际样本、结果、重放参照）与可删 `.dmp` 缓存分目录；每次尝试在独立目录复制校验父档，禁原地覆写；先查全部实际物理时间再整目录发布。
  - 新会话默认分段线性，旧整段平滑显式保留，样本提交即封存、追加不改过去（[ADR-54](../decisions/ADR-54.md)）。
  - `checks` 算判定、`sessions` 按提交规则发布，支持分路、失败恢复和删档重放（[ADR-49](../decisions/ADR-49.md)、[ADR-50](../decisions/ADR-50.md)）；按声明通道校验未知非零通道、不自动补沉降。
- **结果**：公开 `physics` 和 `final` 两层，按状态、对象、参考表面 ID、层、绝对帧返回原序世界坐标；回放前核对参考表面、原始顶点行号、静止坐标与连接关系。粗壳与细面用表面 ID 区分，实验室自有按压脚本等后处理核心不发布（[ADR-52](../decisions/ADR-52.md)）。
  - 不推进物理时间的训练查询单独打包为 Python 3.9 可进程内调用的 `asrp_query`（默认静止基底），避免每次起子进程约 **275 ms** 开销（[ADR-53](../decisions/ADR-53.md)）。
  - 本机 Python 3.13 实测真实嘴唇 10,240 顶点内存热查询 **3.1–3.6 ms**，载入 **219–272 ms**（[E-23](../archive/explanations/E-23.md)）。
  - 已知实验室 Maya 自带 Python 3.9，实际训练调用进程和 NumPy 构建未查（[11](../11-risks-and-questions.md) D22）。
- **演进范围**：切开后，换材料改场景声明与 FEBio 翻译；换粘连算法或网格粗细只重做建造并开新会话，原场景和旧结果不受影响；接新宿主只对接结果层。首版只做 FEBio 一个后端，待第二个真实求解器再抽象通用后端层。

## 三、隔着几毫米到几厘米的粘连为什么这样做

### 1. 实验室的粘连实际长什么样

按演示场景静态导出实测：140 条粘连，全部 `maintainOffset = true`、`attachmentMode = fixed`、`correspondence = worldSpace`、`isHard = false`，单位面积刚度 1×10⁸ N/m³ = 0.1 N/mm³，阻尼 0.01。

- **绝大多数隔着明显间隙**（间距按各边指定目标的**全表面**最近点估算，目标选区未导出；分位数合算该类全部参与顶点；末列为单边中位超 1 mm 的条数）：

| 粘连类型 | 条数 | 静止间距（mm）：中位 / 90 分位 / 99 分位 / 最大 | 中位超过 1 mm 的条数 |
|---|---:|---|---:|
| 组织→骨头 | 42 | 3.9 / 13.6 / 24.4 / 30.4 | 40 |
| 组织→组织 | 36 | 3.2 / 12.3 / 35.9 / 60.7 | 33 |
| 皮肤→骨头 | 22 | 0.0 / 28.4 / 70.8 / 170.2 | 20 |
| 皮肤→组织 | 40 | 8.1 / 16.6 / 27.6 / 34.7 | 40 |

- **49 条带渐变权重，全部以皮肤为源**：19 条皮肤→骨头、30 条皮肤→组织带 0 到 1 间渐变权重；组织作源的粘连只有 0 和 1。
- **目标归属与重叠边**：29% 的参与顶点离同一源物体的**另一个**粘连目标更近，必须按边显式指定目标，不能按最近物体猜。
  - 挂多条粘连的 12 对网格里，参与顶点有重叠的是 **8 对**（同顶点最多同时在 3 条边里，其中 6 对源为外层皮肤且全带渐变权重，[E-23](../archive/explanations/E-23.md)）。目标侧权重图与逐顶点 envelope 图尚未从 Ziva 导出。

### 2. FEBio 现成的 `tied-elastic` 做得到什么、做不到什么

早先 [E-22](E-22.md) 基于 0.5 mm 间隙合成试验建议默认用 `tied-elastic`；本轮补测看清能力边界后，该建议已由 [ADR-51](../decisions/ADR-51.md) 更新：

- **做得到**：在短间距（0.5 mm）、最高 8 块 / 9,814 点合成模型里能保初始间距并支持续算（[E-22](E-22.md)）；同源面挂两条反向拉 `tied-elastic` 平衡位置实测 **−0.6667 mm**，与并联弹簧手算一致（[E-23](../archive/explanations/E-23.md)）。对均匀、短间距、覆盖完整的边，仍可作对照或评估选项。
- **做不到或有硬伤**：
  1. **无法逐点表达渐变权重**：单条接触仅一罚系数，无法按源参考面顶点面积与渐变权重逐点赋刚度；若退回旧导入器“组平均面积”，在手算裁判（两点面积 1 和 9、权重 1 和 0.2、单位刚度与位移）上会算出 **6.0 N**，而真实面积加权应为 **2.8 N**（[E-23](../archive/explanations/E-23.md)）。
  2. **目标转动时间距向量不跟着转**：实测 `tied-elastic` 保持的是静止间距在**世界坐标**里的长度和方向，而非相对目标表面方向；15 mm 间距、目标转 15° 时与“跟着转”差 **3.9158 mm**（与手算 `2·g·sin(θ/2)` 一致，[E-23](../archive/explanations/E-23.md)）。
  3. **漏配对静默正常结束且无界面力**：所测长间距参数下，`search_radius` 留默认 0 找不到接触对、软块纹丝不动，FEBio 只写一条警告仍正常结束（[E-23](../archive/explanations/E-23.md)）；壳法向反时同样表现，且日志给不出 tied 界面力和间隙（[E-22](E-22.md)）。

### 3. 下颌实际转多少度，这件事到底值多大力气

本机统计了实验室全部 84 份运动文件（[E-23](../archive/explanations/E-23.md)）：

- 46 份动了下颌（甩头只有平移，不转）。每份最大转角：**最小 0.37°、中位 2.3°、九成以内 5.2°、最大 6.65°**。
- 按 `2·g·sin(θ/2)` 估算“世界方向”与“跟着转”差值，拿总间距代入是**上界**（实际应取垂直转轴分量且假定目标局部跟下颌同转，不可据此给某边签精度）：最大转角 6.65° 下，间距 **3 mm 差 0.35 mm、8 mm 差 0.93 mm、15 mm 差 1.74 mm、30 mm 差 3.48 mm**。
- **优先级重排**：单靠下颌转动在常见 3–8 mm 间距上差不到 1 mm，不足以把“只旋转”定律排在所有 `tied-elastic` 前（旋转理由降级）。
  - 逐点约束仍居首位的核心原因是**保留 49 条皮肤边渐变权重、保留重叠边各自独立目标、把力和力矩传到正确位置**。
  - 若只把目标约束在表面落点位移上，虽仍能逐点给刚度，但 0.1 N 横向载荷配 15 mm 力臂会在目标侧留下 **1.50000001 N·mm** 力矩不平衡（[E-23](../archive/explanations/E-23.md)）。

### 4. 新做法是什么（ADR-51）

粘连在数据上分**场景声明、建造中逐点对应、FEBio 实现记录**三层，靠边 ID 贯通；每条边独立在源参考面上按逐顶点面积（相邻三角形面积的三分之一）积分刚度 `k = K × A × w × e`，重叠边各自保留并在求解时叠加矢量力，不做“两条边刚度相加成标量”。按目标类型分：

- **可变形目标（组织→组织、皮肤→组织）**：
  - 以目标落点 `q₀` 所在局部支撑四面体为“尺子”，用其四个重心系数 `β` 外推出间隙另一端与静止源点 `p₀` 重合的参考点（不加有质量的假节点）。
  - 用 FEBio 4.13 `<Constraints>` 下 `linear constraint` 沿 x、y、z 三轴拉源点向参考点；须显式写 `<laugon>0</laugon>`（纯罚）、`<rhs>0</rhs>` 与 `<penalty>` 刚度，不可写成 `<Boundary>` 同名硬消元约束。
- **后端等价合并（可选写法，尚未进 FEBio 实跑）**：同边内共享同一组有序支撑节点的多个源点，其罚能量合为同一半正定二次型（四面体配四面体每轴至多 8×8）。后端可用 QR 分解将成百上千点压成每轴至多 8 行、数学等价的约束，保住刚度矩阵与节点恢复力；建造仍保留逐点定义，后端保留逐点模式作基准和裁判，是否默认开启待真实模型计时。
- **刚体目标与旧嘴唇**：已知刚体目标的参考点直接由刚体变换作用于 `p₀` 得到，不从组织四面体估计。两种旧嘴唇（上唇硬、四组全软）共用 `legacy-v1` 建造配置，原样保留已落盘 N/mm 刚度、硬优先与分档，用户改材料不得重算旧弹簧。

### 5. 试验证明了什么、还没证明什么

- **已证明的（本机实测与算术核对）**：
  - **线性罚约束在 FEBio 4.13 里事先登记的 9 项全过**（[E-23](../archive/explanations/E-23.md)；范围仅单个目标四面体合成几何加 5,637 节点代价算例，真实网格、壳源、刚体目标未试）：
    - 静止、平移、绕 Y 轴转 15° 跟随误差 3.1×10⁻¹¹ mm、沿间距拉长 10% 后变为 16.5000000412 mm；
    - 三轴刚度均给出 F/k = 0.2 mm（对照单根轴向弹簧横向失稳报错）；支座反力与按源点取矩均平衡（对照落点版出现 1.50000001 N·mm 力矩差）；源点在单元内部转动和加力均对上手算。
  - **第 9 项动力学续算**：转到一半存档续算（**单线程、一个运动中切点**），比位置、结束时间和帧范围，与整段差 0.0 mm，切点速度仅证当时在动；位置、速度、应力三项预登记检查另见三块组织会话试验（[E-23](../archive/explanations/E-23.md)），不能记成新罚约束或真实皮肤已三项通过。
  - **规模代价算例**（2,025 受粘连节点、6,075 条约束、全模型 5,637 节点）：
    - 线性约束 **9.655 秒**，`tied-elastic` **12.662 秒**，均 **30 次迭代**（[E-23](../archive/explanations/E-23.md)）。此为逐点版对比一轮计时，合并版仅矩阵复算；两者运动不同，不能说“同精度下更快”，只说明该算例未见逐点版更慢。
  - **三条实现坑**：
    - 省略 `<laugon>` 默认增广拉格朗日且**无警告**，同 0.1 N 位移变 **7.5×10⁻⁸ mm** 而非显式写 0 的 **0.2 mm**（[E-23](../archive/explanations/E-23.md)）；
    - 所测可变形目标支撑上，被给定位移目标节点的约束反力不出现在 `Rx`（合计为 0），需外部按 `k·c·β` 重建，刚体目标总力与枢轴力矩另验；
    - 极薄目标四面体（最大系数 150.5）虽收敛，但把目标 0.01 mm 扰动在源点放大 150 倍成 −1.5 mm。
  - **QR 合并独立算术矩阵复算**：32 行压为 8 行，矩阵最大差 1.42×10⁻¹⁴，翻一列符号立刻变 17.12（一次观测值，非预登记容差）。
- **还没证明的**：Ziva 变形目标 `maintainOffset` 究竟按哪条规律走（无 Ziva 等价证据）；QR 合并后 FEBio 输入未实跑、真实压缩比未知；刚体目标逐点约束；罚项动力学时间精度（读源码未乘广义 α 系数，未实跑）；多切点与多线程续算；源节点被给定位移；真实壳源与皮肤小片。

### 6. 最可能错在哪，什么试验会推翻它

- **最可能错在两处**：
  1. **目标组织发生伸缩应变时**：线性外推让间距同时随局部四面体**旋转和伸缩**（沿间距拉长 10%，15 mm 变 16.5 mm）；若 Ziva 仅随局部旋转保定长或只保世界方向，该规律即错。
  2. **长间距配薄或劣质四面体时**：外推产生大正负系数，成倍放大误差、节点力和求解代价；建造须逐边报告间距分布、支撑单元厚度/质量、最大 `|β|`、`Σ|β|` 和受影响面积，退化单元直接拒绝，禁止剪负系数美化报告。
- **推翻它的试验与改法**：
  - **Ziva 上机试验（纯旋转 + 沿间距拉长 10%，辅以剪切、零间距和重复运行估噪声）**：
    - 单旋转可淘汰世界方向（15 mm、15° 差 3.9158 mm），但分不出“只旋转”和“旋转加伸缩”；加 10% 法向伸长后，仿射外推（16.5 mm）与只旋转（15 mm）差 1.5 mm。
    - 若 Ziva 保世界方向，把 `β` 改回重建 `q₀`（并与 `tied-elastic` 比覆盖与成本）；若只随局部旋转，常系数线性约束无法表达，须重做后端或标未支持，不静默退回 `tied-elastic`；若三者皆不符，保留观测轨迹重写假设。
  - **真实切片与动力学核查**：真实嘴周/皮肤小片薄单元扰动与两档网格对照、动力学时间步细分、多切点/多线程续算、合并版与逐点版真实 FEBio 等价对照；任一项不通过则改实现或退回逐点模式。

## 四、现在没定的有哪些，各等什么

[T-43](../tasks/T-43.md) 到 [T-48](../tasks/T-48.md)（旧基线封存、场景版本与安全回放、演示包导入、建造冷启动、单嘴唇续算、失败分支与重放）不需等 Ziva 上机；[T-49](../tasks/T-49.md) 也可先做合成工程验证。以下留白项各等实测证据，不靠猜测代定：

| 现在不定的 | 等什么证据 | 查错了改哪里 |
|---|---|---|
| **参考点按哪条规律走** | Ziva 可变形目标旋转 + 沿间距拉伸（加剪切、零间距、重复噪声） | 切换参考点规律，或将暂达不到规律标未支持 |
| **目标选区和 envelope 近似是否够好** | 补取目标侧权重图和 envelope 图（优先渐变重叠外皮边），比落点/面积/力矩 | 差异可辨则更新场景版本与建造 |
| **目标四面体代表性与薄单元阈值** | 嘴周切片和皮肤小片测转角/应变/厚度/扰动，两档网格同载荷对照 | 定可接受阈值；超范围标未支持或改支撑/网格，不暗换 tied |
| **皮肤降采样尺度、壳类型与双向支撑** | 同原始画权重面、两档计算壳同边界对照面积/极值/节点力/显示面 | 调计算壳配置与绑定；缺曲线蒙皮数据时不发皮肤 `final` 层 |
| **粘连阻尼 `0.01` 怎么对应** | Ziva 与 FEBio 同条件衰减对照 | 补进经验证的后端粘连阻尼映射，或标明适用限制；此前明标“未施加粘连阻尼” |
| **罚项动力学时间精度与边界覆盖** | 固定驱动逐级减时间步比位移/相位/峰值/衰减；补多切点、1/4 线程续算、源点给定位移 | 仅粗网格失真改支撑或网格；动力学精度不够或细化仍偏离 Ziva 时调动力学积分、约束装配或物理模型，收窄允许续算配置 |
| **刚体目标上的逐点约束** | 皮肤→骨偏心刚体传力试验（按需独立验刚体受力与力矩） | 决定刚体边是否支持及后端写法 |
| **合并在真实模型是否默认启用** | 真实场景统计原点数、支撑组数、写出行数、建造/求解耗时与峰值内存，合并版实跑对照 | 多数单元对仅一点则保留逐点写出 |
