# E-20：同一段 AA，为什么我们的嘴张得比 Ziva 大？

- **状态**：有效
- **日期**：2026-11-15 提问（项目负责人看原型回放时指出嘴型不对、嘴角有粘在一起的地方）
- **依据与关联**：
  - [E-19](../13-explanations.md) 基线、[10](../10-decisions.md) [ADR-44](../decisions/ADR-44.md)、[09](../09-roadmap-and-tasks.md) [T-20](../tasks/T-20.md) 卡（粗格子四面体的数）
  - [T-11](../archive/tasks/T-11.md)、[05](../05-ziva-to-febio.md) 第 3 节（软约束换算）、[05-febio-pits](../05-febio-pits.md) 坑 9 与坑 13
  - [11](../11-risks-and-questions.md) D12、D18、Q11、[E-18](../archive/explanations/E-18.md)
- **数据来源注**：下文“分区域走了多少”和三个被排除的试验于 2026-11-15 用一次性脚本量出（脚本不在仓库里）；可用产品命令重做的部分见文末。

## 核心结论

- **差别在上唇，原因是四面体的粗细（上下唇是否共用格点），不是材料也不是粘连。**
- 在实验室中性到 AA（下颌转 −5.16°）物理层第 36 帧对第 14 帧上：Ziva 里上唇被带着往下走近 5 mm，嘴只张开一条缝；我们的细网格上唇粘在颅骨不动，嘴一直张到嘴角。
- 把四面体换成与 Ziva 同样粗的规则格子（格边 25.4 mm，上下唇落在同一批格子里），上唇跟着往下走，渲染出的嘴型与 Ziva 看不出差别。

同一批顶点平均走了多少（物理层，第 36 帧对第 14 帧）：

| 位置 | 我们的细网格 | Ziva 整张脸 | Ziva 只留嘴唇 | 我们的粗格子 |
|---|---|---|---|---|
| 下唇中间 | 12.21 mm | 10.05 | 9.81 | 8.72 |
| 嘴角 | 4.17 | 4.78 | 4.17 | 4.68 |
| **上唇中间** | **0.15** | **4.80** | **4.56** | **4.20** |

## 排除与对照试验

| 试验 | 第 36 帧对 Ziva 整张脸（平均 / P95 / 最大 mm） | 上唇中间走了 | 结论 |
|---|---|---|---|
| 基线：细网格，Ziva 材料，我们的粘连 | 2.212 / 4.913 / 7.638 | 0.15 mm | 即 [E-19](../13-explanations.md) 的数 |
| 四组粘连全改 Ziva 软约束（0.1 N/mm³ × 顶点面积 × k²） | 2.278 / 4.825 / 7.647 | 0.22 mm | 排除：软硬几乎无影响 |
| 只把上唇改成软约束 | 2.249 / 4.813 / 7.627 | 0.22 mm | 排除 |
| 物理尺度 k 从 0.67 改 10.4（1 场景单位当 1 厘米） | 没有数 | 没有数 | FEBio 不收敛（负体积），今天无答案 |
| 粗格子 25 mm，上下唇共用格点（试验格子位置） | 2.062 / 3.763 / 5.553 | 4.20 mm | 上唇跟着走了 |
| 粗格子 12.5 mm，同样共用 | 1.903 / 3.946 / 5.307 | 5.29 mm | 同上 |
| 粗格子 12.5 mm，把格子沿嘴缝切开 | 2.033 / 4.311 / 6.775 | 0.82 mm | 对照：一切开，上唇又不动了 |

- **关键对照**：最后两行格子同样粗，只差上下唇连不连，上唇走 5.29 mm 对 0.82 mm；因此真正起作用的是“上下唇在计算里是不是一个整体”，粗细本身只是让它们连在一起的原因。
- **产品落盘版粗格子**（`data/tetmesh/lips_lattice.json`，126 个四面体，格子位置按事先定规则取，[ADR-44](../decisions/ADR-44.md)）：
  - 第 36 帧对 Ziva 整张脸：平均 1.883、P95 3.597、最大 5.116 mm，上唇 5.51 mm。
  - 格子平移半格：平均在 1.89 到 2.19 mm 之间变，上唇在 4.78 到 5.55 mm 之间变；结果依赖格子位置，这是该方法本身的性质。

## 这说明什么、不说明什么

- **说明**：我们和 Ziva 在嘴型上的差别主要来自四面体网格的做法，[E-18](../archive/explanations/E-18.md)“Ziva 算得粗”的推断在嘴型上得到直接证据。
- **说明**：换粗格子后每帧求解从约 0.45 秒降到约 0.01 秒（当时机器还有别的任务在跑，只能看量级）。
- **不说明** Ziva 自己的四面体就是这样：Ziva 四面体网格未取回（[11](../11-risks-and-questions.md) D12），“共用格子”是从行为上对出来的（🔍）。
- **不说明**哪种更接近真人：细网格上下唇各自动更像真实嘴唇，粗格子像一整块；因实验室参照是 Ziva，原型默认用粗格子，细网格保留可选（[ADR-44](../decisions/ADR-44.md)）。
- **指标提示**：平均差仅从 2.21 降到 1.88 mm，整体平均分不出嘴型对错，需看 P95、最大值和分区域数；剩余差别未查（重力下垂和物理尺度仍未对齐，D18）。
- **未有参照的运动**：下颌张开 12° 测试运动上，粗格子上唇跟着下颌走 12.1 mm、嘴只张开 9.3 mm（细网格 27.0 mm）；该运动无 Ziva 参照，哪个对不知道。

## 嘴角“粘在一起”是什么

- 细网格在嘴角处上下唇连着：实验室嘴唇表面在那里上下唇互相穿过（[05-febio-pits](../05-febio-pits.md) 坑 9、坑 13），四面体把穿过一段合成一块，外侧还留着两个小孔（Q11）。
- 嘴张得越大该段拉得越明显，12° 时像一根柱子；粗格子里整条嘴缝都连着，嘴角不再单独显出来。

## 用产品命令重做

```bash
uv run asrp import-asset data/lab_export <场景文件夹> --tissue-settings lab --tetmesh data/tetmesh/lips_lattice.json --attachments ziva-soft
uv run asrp run <场景文件夹>/scene.json data/lab_export/trajectories/neutral_to_AA.json
uv run asrp compare <运行文件夹> <Ziva 的导出文件夹> --out <输出文件夹>
```

- `asrp compare` 给出每帧平均、P95、最大差（[T-11](../archive/tasks/T-11.md)）；去掉 `--tetmesh` 和 `--attachments` 即为细网格基线；Ziva 导出文件夹在仓库外。
