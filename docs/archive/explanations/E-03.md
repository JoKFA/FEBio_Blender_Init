# E-03：T-04 初版的四面体网格为什么不能直接当地基？

> **归档说明**：原型期阶段性说明，原样归档留存。

- **状态**：有效（含 2026-11-13 材料占位值注）
- **日期**：2026-11-09 提问；2026-11-13 补充
- **依据与关联**：
  - [09](../../09-roadmap-and-tasks.md) [T-04](../tasks/T-04.md)、[10](../../10-decisions.md) [ADR-20](../../decisions/ADR-20.md)
  - [05-febio-pits](../../05-febio-pits.md) 坑 9–15、[02](../../02-requirements.md) R-06、[E-11](../../explanations/E-11.md)

## 核心结论

- 初版（提交 7876194）证明了 fTetWild 能切这个自身穿插的嘴唇网格，但有六个硬伤：不可复现、嘴缝时粘时不粘且左右不对称、边界拓扑不稳、从未进过 FEBio、贴合差、ADR-20 插错位置。
- **最终方案（现行做法）**：网格**只生成一次**，通过一组会失败的检查后提交在 `data/tetmesh/lips.json`（包络固定 0.12 mm、边长 25.4 mm），运行时只读并校验哈希。
- 该网格已在 FEBio 里跑通重力沉降（6,747 个计算点、26,721 个四面体、最小二面角 10.4°），具备当地基的条件。
- **2026-11-13 注**：本文测试所用的材料值（E 20 kPa、泊松比 0.45）是占位值；Ziva 里 43 个材料全部相同：杨氏模量 12 kPa、泊松比 0.4、密度 1060、体积保持项 0（2026-11-12 实测，[E-11](../../explanations/E-11.md)）。

## 最终方案与质量检查

- **生成一次，落盘**：`uv run python tools/build_tetmesh.py` 调 fTetWild（包络 0.12 mm、边长 25.4 mm），跑 `tetmesh.check`，通过才写 `data/tetmesh/lips.json`。
  - 不通过就重试（每次结果不同），重试用完就不写。
  - 文件为 JSON，带格式版本、单位 mm、Z 轴朝上、`mm_per_scene_unit`、源表面 sha256、参数、工具版本、全部检查结果和内容哈希。
- **只读不生成**：后续任何运行都用 `tetmesh.load` 读，重算内容哈希，对不上就报错；`tetmesh.check_source` 确认源表面没变。
- **参数为何取 0.12 mm**：比较表见 [10](../../10-decisions.md) [ADR-20](../../decisions/ADR-20.md)。

### 质量检查项（`tests/test_tetmesh.py`）

每一条检查都有一个让它失败的合成小例子：

| 检查 | 让它失败的例子 |
|---|---|
| 没有反向或压扁的四面体 | 把每个四面体两个角对调 |
| 最小二面角 > 5°、最小体积 > 0.001 mm³（硬下限） | 压得很扁的四面体；很小的四面体（详见表下测试名） |
| 单连通（四面体之间靠共面连着） | 两个分开的方块；只共一条边的两个方块 |
| 边界流形（每条边正好两个面，点周围面连成一圈） | 只共一条边、只共一个角的两个方块 |
| 边界亏格等于表面围出的实体的亏格 | 嘴缝填实的环（亏格 0）；把嘴角小孔填上的网格 |
| 上下唇分开宽度 ≥ 表面真正分开宽度的 95% | 一侧焊住一段的环 |
| 左右少掉的宽度差不超过一个单元边长（中位数） | 同上，只焊一侧 |

- 硬下限对应测试：`test_check_fails_a_sliver_on_the_dihedral_floor_only`、`test_check_fails_a_tiny_tet_on_the_volume_floor_only`。
- 故意改坏每条检查代码时，对应测试都会失败（12 处）；去掉重力反号（[05-febio-pits](../../05-febio-pits.md) 坑 1），FEBio 测试失败（平均下沉变成 +3.75 mm）。

### 亏格为何是 3 而不是 1

- 最初要求“边界亏格等于输入表面”（1），但嘴唇表面自身穿插：两侧嘴角上下唇先互相穿过，再往外 `|x|` 29.4–30.9 mm 又分开一小段（约 0.17–0.29 mm 宽），前后贯通。
- 这两段是表面围出实体上的两个小孔，因此忠实网格的亏格是 3（[05-febio-pits](../../05-febio-pits.md) 坑 13）。
- 紧包络每次都得到 3；按 x 切片看，网格分开的三段与表面三段一一对应。
- 若强求亏格 1，需用 0.5 mm 以上粗包络填小孔，但嘴缝收窄处几乎每次留非流形：0.5–1.27 mm 共 64 次重复，按“亏格 1 + 流形 + 分开 95% + 左右差”算只有 1 次全过。
- 因此检查改为“等于实体的亏格”（表面亏格 + 穿过之后又分开的段数）；只是焊住、没有穿过的，不算小孔。Ziva 如何处理这两个小孔，挂在 [11](../../11-risks-and-questions.md) Q11。

### 为什么现在可以当地基用

- **可复现**：大家读同一个文件，哈希锁住，改一位就读不进来（`test_load_refuses_an_edited_mesh`）。
- **质量有硬数字**：
  - 6,747 个计算点、26,721 个四面体，最小二面角 10.4°。
  - 上下唇分开 51.25 mm，是表面 51.75 mm 的 99%，左右差 0；单连通、边界流形，亏格 3 = 期望 3。
  - 95% 的显示顶点离四面体不到 0.07 mm，最远 0.93 mm（正中嘴缝最深处折痕）。
  - 上述数字写在文件里，`test_saved_lip_mesh_is_intact_and_passes_the_checks` 每次重算对照。
- **进过 FEBio**：
  - 背面 5 mm 内的 579 个点固定，仅受重力，动力学 15 帧：正常结束且 15 帧全部收敛，本机 22 秒。
  - 固定点最多动 4.9×10⁻¹⁰ mm，其余点平均下沉 4.26 mm（无阻尼动力学下的逐帧平均，逐帧在振荡）。
  - 复现：`uv run python tests/s2_lips_febio.py smoke`、`test_saved_lip_mesh_settles_under_gravity_in_real_febio`。
  - 材料为占位值（E 20 kPa、泊松比 0.45），真值等 Q4；仅证明网格进得了 FEBio、算得完，不证明沉降量对。

## 下颌张开压力测试（I1，给 T-06a/T-07 的证据，不是合格线）

- 做法：嘴唇背面 5 mm 内的点按嘴缝高度（中线处 z = −82.16 mm）分上下两组，上组固定、下组并进刚体下颌。
- 下颌绕真实铰链 jaw01 转动：场景坐标 (0, −56.81, 126.52)，换算为毫米、Z 朝上后为 (0, −121.71, −54.65) mm，转轴为 x；1 秒内张开 15°，30 帧，材料同上。

| 版本 | FEBio 状态 | 下面一组平均下降 | 最大拉伸 | 超 3 倍四面体数 |
|---|---|---|---|---|
| 按高度一刀切（任务要求的粗规则） | ❌ 第 12 帧后不收敛（0.4 s，6.0°），28 次重试 | 10.4 mm | 15.5 | 214 个 |
| 嘴缝上下各 5 mm 不约束 | ✅ 30 帧全部收敛，11 次重试，66 秒 | 24.9 mm | 8.7 | 1,057 个 |

- **按高度一刀切详情**：第一次不收敛在 0.124 s（约 1.9°）；最大拉伸在右嘴角背面 (42.5, −22.3, −82.6) mm；损坏集中在沿分界线背面整排（x −43.9 到 43.8，z −84.3 到 −79.9 mm）。
- **留 5 mm 过渡带详情**：最大拉伸在左嘴角背面 (−31.7, −18.0, −77.4) mm；高拉伸集中在背面靠近嘴缝一带，两侧嘴角最重。
- **结论**：留过渡带虽算完，但用了 11 次重试、最大拉伸 8.7，不是合格线，只说明一刀切的绑法不行（分界线两侧一点固定、一点随下颌动，中间只隔一个单元）。
- [T-06a](../tasks/T-06a.md)/[T-07](../tasks/T-07.md) 定粘连区域时，固定区与随下颌区之间要留过渡带；留 5 mm 后背面拉伸仍有 8 倍多，说明“背面整条固定”本身太硬，粘连应按 [T-03](../tasks/T-03.md) 算出的区域来。
- 复现：`uv run python tests/s2_lips_febio.py jaw` 和 `uv run python tests/s2_lips_febio.py jaw runs/s2_lips_jaw_gap 5`。

## 以后可能换的做法：规则格子（T-20）

- 现有办法的毛病：fTetWild 每次结果不同、偶尔崩溃、会在嘴角小孔处出极小四面体，并依赖锁版本的第三方包（`pytetwild` 0.2.x）。
- 另一条路是用整齐格子罩住表面，保留实体内部格子，同一格内上下唇不相连部分各自成格；该法确定、不怕表面自相交，Ziva 自己即属此类。
- 网格已是独立文件，换生成办法不影响下游，因此记成 [T-20](../../tasks/T-20.md)。
- [T-06a](../tasks/T-06a.md) 首次运行未出现嘴角小四面体问题，故 T-20 不是救急。
- 它与 [T-17](../tasks/T-17.md)、[T-23](../tasks/T-23.md)、[T-24](../../tasks/T-24.md) 一起在第二阶段投入前完成（[09](../../09-roadmap-and-tasks.md) 第 2 节），过同一套检查与 FEBio 测试并排比较。

## 历史与修订：初版（提交 7876194）的六个实测问题

| # | 问题 | 核心实测结果 | 复现方式 |
|---|---|---|---|
| 1 | **不可复现** | 同一台机器、同样输入，25.4 mm 档连跑三次得 360 / 348 / 344 个节点，哈希均不同 | `uv run python spikes/s2_tetmesh.py 3` |
| 2 | **上下唇焊住、左右不对称** | 按复核后的参照（下面“问题 2 复核”），初版参数 21 次重复里分开宽度在表面的 83%–118% 间乱跳，左右差最多 9 mm | 同上；`tetmesh.check` 的 `separation`、`asymmetry_mm` |
| 3 | **拓扑不稳** | 边界亏格时而 1 时而 2；21 次里 18 次有非流形边或点 | 同上，看 genus 和 non-manifold 两列 |
| 4 | **从没进过 FEBio** | [11](../../11-risks-and-questions.md) A-10 标了 ✅，但只看了二面角和体积 | — |
| 5 | **贴合差、“边长”名不副实** | 25.4 mm 档 70%–76% 显示顶点在四面体外，最远 0.85–1.08 mm | 同上 |
| 6 | **ADR-20 插错位置** | ADR-19 最后一行“取代：N-06…”掉到了 ADR-20 末尾 | `git show 7876194 -- docs/10-decisions.md` |

初版问题实测细节：

- **问题 1 复核**：`num_threads=1` 时仍得 360 / 333 / 328 个节点，关掉简化或优化也一样（[05-febio-pits](../../05-febio-pits.md) 坑 12）；R-06 要求同输入重跑结果逐位相同。`uv run python spikes/s2_tetmesh.py 3` 每档重复 3 次，节点数每次不同。
- **问题 2 复核**：
  - 审计按 x = 常数切片：原表面上下唇分开 61.5 mm 宽，四面体网格只剩 48–50 mm 且左右不对称；中线处间隙 1.84 mm，x = 20 处 0.81 mm，小于包络 1.27 mm。
  - 复核修正了参照：原表面在 `|x|` 26.0–29.25 mm 处上下唇**互相穿过**（坑 9），该段不算分开；真正分开（截面不相交）为 `|x| < 25.9 mm`，宽 51.75 mm。
- **问题 3 细节**：非流形边或点均出现在嘴缝收窄到与包络差不多宽的位置（`|x|` 22–33 mm）。
- **问题 5 细节**：三档合起来显示顶点最远在四面体外 1.76 mm；设“边长 25.4 mm”，实际边长中位数仅 8.2–9.1 mm。当时把包络绑在边长上是为了让节点数接近 Ziva 的 `tetSz`，但项目目标不是复刻 Ziva（[ADR-17](../../decisions/ADR-17.md)）。
- **问题 6 细节**：ADR-20 插进了 [ADR-19](../../decisions/ADR-19.md) 中间。
